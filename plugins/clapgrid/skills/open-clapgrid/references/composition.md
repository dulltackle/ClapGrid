# 画面编排制作约定

本文是口播片段画面编排的唯一规则来源：素材归属、编排、页面图层、风格、制作者自检与片段合成预览。何时开始、做到哪一步等 agent 行为见[打开 ClapGrid](../SKILL.md#逐句画面素材)；风格的编写约定见[内置风格](../../../styles/README.md)。

## 素材与归属

使用 `clapgrid_import_material` 导入本地 PNG、JPEG 或视频。图片保持原生身份和透明通道，透明角色使用保留 alpha 的原生 PNG；视频生成静音 WebM 原件预览。仅复制用户指定的普通文件，拒绝符号链接、多硬链接、播放列表和网络引用，不扫描相邻目录。

使用 `clapgrid_modify` 确认本句使用的素材。移出及删除片段保留项目素材，同一原件可供多句复用。添加素材只确定本句使用哪些素材，不决定展示时间，不自动均分时长、贯穿整句或跨句套用。

## 编排

先生成有效配音，再用 `clapgrid_visual_context` 读取本句内容和配音的精确解码时长。缺失或待更新的配音会明确拒绝。用 `clapgrid_modify` 保存编排。

- 编排时长须与有效配音时长一致。
- 背景须连续覆盖整句，本句全部素材须进入编排。同一素材可在多个区间重复引用。
- 导入、关联和编排遵循项目修改权，更新前核对最新片段快照。失败保留已提交状态，断线后先查询确认。

旧单视频与多视频项目保留素材身份、关联、顺序和起点。既有旧单视频记录可按原方式导出。通过兼容入口重新关联视频后，或制作尚无明确编排的旧多视频片段时，须先完成编排。

用户通过对话要求移动角色、调整出现时机时，重读该句输入、提交新编排并重新生成预览，保留无关片段和项目原件。

## 页面图层

页面用于逐帧动画背景、镜头推拉和透明叠加。

### 导入

在用户工作空间内编写含 `index.html` 的目录，用 `clapgrid_import_page` 导入为项目 `pages/<SHA-256>/` 内的不可变副本。同一内容重复导入复用身份。显式项目入口以项目父目录作为工作空间边界。导入限制见[导入边界](#导入边界)。导入时会提示常见的不确定 API，静态提示可能误报。修改页面后重新导入，用新页面身份更新编排，旧预览自动待更新。

### 运行约定

- 页面暴露 `window.DUR`（秒）、`window.render(t)` 和加载完成后的 `window.READY = true`，可选 `window.TEXTS(t)`（见[制作者自检](#制作者自检)）。字体、图片、模块及素材须在 READY 前加载完毕，最多等待 120 秒。
- `t` 以图层起点为零点。DUR 须与图层区间时长一致，误差不超过 1 ms。帧数为 round(DUR×fps)，不足一帧会明确失败。
- `render(t)` 必须独立确定，不依赖上一帧、当前时间或无种子随机数。
- 视口按图层在 1920×1080 画布上的实际尺寸四舍五入到最近偶数（至少 2 px），设备像素比 1，以 innerWidth/innerHeight 布局。
- 页面只能读取自身文件、经 `/style/` 提供的项目风格和图层声明的本句素材；依赖保存在页面或项目风格目录内。外网、任意本地路径、WebSocket、WebRTC、Worker 和嵌入框架均被拒绝。
- 页面只输出画面。ClapGrid 在页面和素材图层上方叠加由项目风格绘制的透明字幕层；字幕模块约定见[内置风格](../../../styles/README.md#字幕模块)。

### 编排与渲染

页面图层声明的本句素材计入编排覆盖校验。页面背景同样须连续覆盖整句。

页面渲染失败会在任务问题中指明片段与原因，不产生成片。渲染使用固定浏览器、软件渲染和双页面实例产生 FFV1 中间视频，与预览及导出共用滤镜链；组件来源见 [Linux 组件](https://github.com/dulltackle/ClapGrid/blob/main/docs/linux-components.md)，决策见 [ADR0015](https://github.com/dulltackle/ClapGrid/blob/main/docs/adr/0015-page-rendering.md)。

## 风格

风格由 `STYLE.md`、含 `subtitle.js` 的 ES module `lib/` 和 `example/` 组成。项目采用的规则仍记录在视觉方案中，风格本身不代表已被采用。

1. 阅读所选内置风格的 `STYLE.md`，将整个风格目录复制到工作空间 `styles/<id>/`，在 `STYLE.md` 头部追加来源 id/version，保留项目版本自己的 id 与 version。插件更新不改变此独立副本。
2. 在 `video.md` 的“风格”小节链接该目录的 `STYLE.md`。先完成本项目的结构方案和视觉方案，再阅读风格示例源码、编写第一个页面。结构方案按[项目制作约定模板](https://github.com/dulltackle/ClapGrid/blob/main/docs/templates/video.md#结构方案)记录，仅供制作者自检，不作为审阅证据。按 `STYLE.md` 的修改分级调整项目风格。
3. 用 `clapgrid_import_style` 导入风格。不可变副本存于项目 `clapgrid/styles/<SHA-256>/`。同一内容重复导入返回相同身份；修改工作副本后重新导入，不编辑已导入副本。导入遵循现有修改权流程，限制见[导入边界](#导入边界)。
4. 核对项目状态后，用 `clapgrid_set_project_style` 设置项目风格。面板显示当前风格，项目状态及 `clapgrid_visual_context` 返回风格身份与来源。
5. 页面以绝对路径引用项目风格，例如 `import { draw } from '/style/lib/draw.js'`。渲染时只开放当前项目风格；未设置风格时请求 `/style/` 返回 404，并使任务失败、指明片段。旧 `page.json` 的 `style` 字段会被拒绝。
6. 使用示例时，将 `example/` 复制到风格目录外的页面目录，按实际图层区间调整 DUR，再导入页面。
7. 根据字幕模块的 `subtitleRegion` 为字幕留出画布空间。导出前必须设置项目风格；未设置时片段合成预览会标明字幕缺失，全片导出被拒绝。

风格变化后重新导入并设置新身份，原页面引用继续生效，旧预览随之显示待更新。同时更新采用方案中的风格身份，重新展示动态样片并取得受影响范围的确认；样式稿可选。确认记录格式见[样片接入说明](https://github.com/dulltackle/ClapGrid/blob/main/docs/production-sample.md)。

交付前与示例比较六个维度：题材与对象、构图、配色、材质、运动与镜头、转场，至少四项不同，并在项目方案中记录差异。这是制作者自检，工具不机械核对，也不作为审阅证据必需项。

## 导入边界

页面与风格共用白名单 html/js/mjs/css/json/svg/png/jpg/jpeg/webp/woff2/ttf/otf/md，最多 256 个文件、32 MiB（含说明与示例）。按相对路径及实际字节计算 SHA-256；拒绝符号链接、多硬链接、特殊文件、目录外引用和工作空间外路径。已存在副本只核对，不覆盖；使用前再次核对完整内容身份，篡改副本被拒绝。纯函数、说明栏目和美术效果由作者自检与观看确认。

## 制作者自检

对当前编排中的页面图层使用以下工具，定位阅读时长、排版和画面不确定性问题。

- `clapgrid_check_page` 检查文字停留、排版和渲染确定性。页面可在 `render(t)` 后用 `window.TEXTS(t)` 返回当前可见文字及页面像素框 `[{text,x,y,width,height,id?}]`；同文案的不同元素宜用稳定的 `id` 区分。没有 `TEXTS` 时返回 `not-checked`。
  - 结果时间以图层起点为零，像素框以输出画面左上角为原点；连续几帧发生同类几何问题时报告首个问题框。
  - 检查文字是否停留足够、是否出框、是否挡住字幕。阅读时长阈值采用 opuscar 默认公式（汉字数 ÷ 4.5 + 其他字符数 ÷ 15 + 1.5 秒），尚待 ClapGrid 样片校准。字幕区域取自项目风格字幕模块的 `subtitleRegion`；未设置项目风格时单独标为未检查。
  - 确定性检查比较少量局部时间在两个页面实例中按不同顺序渲染的像素，并对随机闪烁或跳帧给出警告；通过抽检不能证明所有帧都确定。
- `clapgrid_page_frames` 提取单个页面图层的静帧。返回的 PNG 位于项目 `.cache/page-inspection/`，透明图层保留透明，文件可删除重建。

### 审片顺序

1. **接触印样。** 用 `clapgrid_contact_sheet` 从当前片段合成预览或已成功的成片抽帧，一起看字幕、页面和素材的构图与节奏。总览每 1–2 秒取一帧。整片按时间段分批取帧，每批最多 60 帧。片段合成预览使用片段内时间，成片使用全片时间。接触印样与可放大检查的原图保存在项目 `.cache/review-frames/`，可删除重建。
2. **关键动作帧条。** 用同一工具在动作附近按约 0.2 秒间隔取帧。检查片段衔接时，从 `clapgrid_export_status` 读取片段的画面切点 `visualStart`，用 `times` 指定切点前后的时间。
3. **技术检查。** 从 `clapgrid_export_status` 读取成片导出的 `technicalChecks` 和 `warnings`，核对标准化前后响度，并按黑场警告中的片段及全片时间回看画面。此步骤属于制作者自检，审阅证据另行记录。
4. **有声全速看片。** 以正常速度完整播放一次，检查声音、字幕、动作和衔接配合。

**一轮修完。** 将本轮发现的问题集中修正，再复查一次。复查发现的小问题计入同一轮，较大的问题在交付说明中用一句话说明。交付后用户提出的修改另算一轮，范围限于用户要求。

交付前将本片的接触印样与所用风格的示例画面并排对照，确认本片的构图和图示针对自己的内容重新设计。示例画面可直接打开页面查看。

接触印样和页面图层检查仅用于制作者自检，结果不写入项目记录，也不是审阅证据。自检结果不阻止片段合成预览或导出。

## 片段合成预览

`clapgrid_preview_segment` 受理真实合成，使用 `clapgrid_visual_previews` 查询终态；只有 `succeeded` 且 `current: true` 表示当前输入的可审阅结果，受理、缩略图或原件查看都不代表合成成功。任务期间沿用项目占用、取消、清理与中断恢复规则，取消使用 `clapgrid_cancel_export`。

片段合成预览和全片导出共用渲染器执行已保存编排，真实混合透明通道，短视频冻结末帧；缺失或过期编排明确失败。相关内容或编排变化后，旧预览显示待更新。
