# 显式迁入旧项目

仅用户明确要求迁入并指定来源时执行；先迁入，再打开当前工作空间项目。

1. 取得用户明确指定的旧项目绝对路径，以及确认无运行任务。源服务必须正常退出，包括空闲服务。仍有制作任务时等待结束；迁入不能中断任务。无法取得确认时说明需要这项确认才能迁入。
2. 核对当前本地工作空间与聊天身份，检查 Node.js 组件。Linux 使用 `bash <插件根目录>/scripts/runtime-linux.sh import-project --workspace <当前工作空间> --thread <当前聊天ID> --source <旧项目绝对路径> --confirm-idle`；其他系统使用 `node <插件根目录>/dist/runtime.js` 和相同参数。只有取得第 1 步确认才传 `--confirm-idle`。
3. 等待命令成功。源服务或媒体进程仍在运行、存在未完成任务、目标已有目录或复制校验失败都会拒绝。保留原件，不删除目标或锁来强行继续，不自动重试制作。
4. 成功后按日常打开流程核对目标项目，查看文案、素材、配音和任务历史，试听及访问已有成片。迁入建立新的项目身份，任务和片段身份保留；返回的项目目录必须是当前工作空间的 `clapgrid/`。

正常失败会清理本次暂存内容。强制中断可能保留工作空间根目录的 `.clapgrid-import/`，普通打开会明确拒绝；该目录不是完成的项目。报告其路径并保留现场，先核对迁入进程已退出和目标状态，再单独处理恢复。不得把关闭重开当成迁入成功。
