# 全片导出设置

## 使用与保存

表格的「导出设置」入口显示项目设置、当前字体及检查结果；「编辑设置」取得普通修改权。编码、帧率、字体改变后自动保存，字号在离开输入框或按 Enter 时保存。编辑期间保持修改权，关闭或断线释放；保存失败明确显示错误并保留原设置。任务锁期间允许查看，不能编辑。

MCP 使用 `clapgrid_export_settings` 查询，`clapgrid_set_export_settings` 携带原 `expected` 和完整 `settings` 修改。取得修改权后重新读取，过时快照拒绝；同一次请求不重试。HTTP 表格写入口要求 `X-Edit-Token`，MCP 写入口自行申请和释放修改权。SQLite 随修改提交；老项目没有记录时使用默认值，字体字号仍为空。

## 参数与选择依据

| 参数 | 默认值与支持范围 | 依据 |
| --- | --- | --- |
| 编码 | 默认 `libx264`（H.264），可选 `mpeg4`（MPEG-4 Part 2） | 两种编码均用实际 FFmpeg 写入 MP4，并用 ffprobe 检查及完整解码。默认 H.264 使用 yuv420p，面向常见播放器；另提供 FFmpeg 原生 MPEG-4 Part 2。当前环境不支持所选编码时明确拒绝，不偷偷切换编码。 |
| 帧率 | 默认 30 fps，可选整数 24、25、30、50、60 | 有限支持集覆盖常用帧率，十种编码/帧率组合均以真实 1080p 媒体验证；分数帧率及任意数值不在本版支持范围。 |
| 字体 | 首次 `null`，不预选 | 运行 `fc-list --format '%{family[0]}\n'` 枚举本机 Fontconfig 字族，选择后按完整名称校验；不自动下载字体，不以替代字体掩盖所选字体缺失。字体名中的逗号、换行和空字符不受支持，避免破坏 ASS 样式记录。 |
| 字号 | 首次 `null`，不预填；整数 1–1080 px | 以 ASS `PlayResX=1920`、`PlayResY=1080` 的画布像素解释字号，不依赖屏幕 DPI；指字体标称大小，不保证每个字形恰好占同样高的像素。上下界限制单画布尺度，实际渲染高度由字体决定。 |
| 输出 | 固定 16:9、1920×1080、MP4、yuv420p | 不能通过设置接口修改分辨率、比例或容器。 |

字体、字号允许分步保存或清空；缺少任何一项时导出读取入口拒绝，并一次反馈缺失项目。完整配置保存时实际烧录一份临时 ASS 字幕并编码/解码；字体按当前环境重新枚举，缺少媒体组件或无法渲染时拒绝保存。临时探测文件在系统临时目录内清理，不写入项目成片目录。

## 媒体环境与跨平台范围

需要 PATH 中的 FFmpeg、ffprobe、Fontconfig 的 `fc-list`。FFmpeg 需包含 libx264、原生 mpeg4、libass，并使用 Fontconfig 字体提供者；探测不符合时反馈安装/构建要求。Windows、macOS 同样需要这套组件与字体配置，不能把 Fontconfig 枚举结果直接交给另一字体提供者。新安装或卸载字体后重新打开设置入口刷新列表；下一次导出还会重新校验。

本次自动测试在 Linux 上验证两种编码、五种帧率、中文字体烧录、组件缺失、设置保存恢复、修改权与配音锁。Windows/macOS 的组件安装和实际运行仍须由 #11、#12 的平台验收验证；不能将 Linux 结果视为三平台通过。

## 后续导出接入

`business.getCurrentExportSettings()` 返回经过当前环境验证的独立设置值及固定输出参数，缺少必填项、环境不可用、项目正在修改或配音进行中均拒绝。异步探测完成后再比较当前设置，防止采用过时配置；后续导出任务须在自己的任务锁边界调用并固定返回值。`exportEncodingArguments` 提供与探测一致的编码输出参数。

#24 只实现设置与导出前读取，不实现全片导出任务、取消、字幕布局或成片生成。修改设置不写配音、片段或 `exports/`，已有导出快照与文件不变；后续每次任务须重新读取当前设置。完整成片采用设置的端到端验证留到导出任务接入后执行。

参考：[FFmpeg subtitles 过滤器](https://ffmpeg.org/ffmpeg-filters.html#subtitles)、[Fontconfig 开发文档](https://fontconfig.pages.freedesktop.org/fontconfig/fontconfig-devel/)、[fc-list 手册](https://xorg.freedesktop.org/archive/X11R7.0/doc/html/fc-list.1.html)。
