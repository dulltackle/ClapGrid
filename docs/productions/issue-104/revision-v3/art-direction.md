# 第三版生图与动画约定

用户看完第二版仍要求提高素材质感，尤其整根股骨，并充分利用生图保持统一。第三版复用同一配音、确认原文、稳定身份和原速，整片原声68.04秒。新素材由内置 image_gen.imagegen 生成，完整股骨为风格起点，近端剖面、正面剖面和组织近景沿同一参考链；不是 Google Imagen。白底原件在合成中正片叠底，不宣称透明图片。提示词、生成原件、试验版本和SHA见 evidence/image-generation.json及public/artwork-v3。

素材静态核心来自生图；镜头、圈选、引线、细胞状态、血流、负重和下陷由帧驱动。局部放大使用同一素材，组织修复只将生成变体的两个独立局部合入原件。既有裂隙恒在实体骨梁处，负重慢下压不触发新裂。连续位移场作用于整个关节剖面，软骨及其下骨层一起变化，骨底固定，原轮廓作为独立对照。

完整股骨1024×1536，头锚点(326,120)，归一k=.41。近端剖面1145×1374，骨内锚点(365,315)，k=.6。正面剖面1254×1254，k=.4、放置(-250.8,-199.2)，软骨/薄骨层/骨梁引线local(0,-135.2)/(0,-77.2)/(47.2,14.8)。组织1448×1086，k=480/1448、放置(-240,-180)，统一比例保留。

每段前14帧保留上一段末帧，纸边擦入当前画面；原声不重叠、不剪短。每幕主要动作结束后留停顿，底部字幕保留。所有静态和动态示意只用于机制解释，无分期、治疗、概率或必然病程，不引入真实血管命名。有限无损帧与技术检查不能代替用户完整医学、风格、字幕、发音、节奏和FH10前后终审。
