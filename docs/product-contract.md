# 产品契约

本文记录首版口播视频制作的产品规则、验收清单与交付门槛。术语见 [GLOSSARY.md](../GLOSSARY.md)；实现入口、接口与命令见 [README](../README.md)。本文描述应满足的契约，不表示产品已实现或验收通过。

多素材、画面说明、画面编排、页面图层、风格与片段合成预览属于首版之后的扩展，规则见 README 的[画面素材与编排](../README.md#画面素材与编排)、[面板规范](panel-style.md#表格信息组织)、[ADR0015](adr/0015-page-rendering.md) 与[风格指南](styles.md)。本文中以“关联视频”“视频起点”表述的规则按首版单视频关联编写，适用于旧单视频记录；多素材的时长匹配与导出验收尚未扩展进本文，不能直接视为已经确定。

## 目标与范围

通过 Codex 插件，在 Codex 右侧表格中组织一条配音搭配画面的口播视频。用户编辑文案、关联画面素材、生成并试听配音，最后导出带字幕的粗剪。Codex 通过业务 MCP 操作同一项目，与表格共享业务规则和状态。

首版支持 Windows、macOS、Linux，采用本地存储，一个工作空间固定对应一个项目，不同工作空间允许并行制作。按小规模单视频生产设计，以一条 20～30 个口播片段的视频验收；这个数量是样例规模，不是硬性上限。

首版包含：

- 本地项目创建、打开、自动保存与恢复。
- 口播片段新增、编辑、删除、手动调整顺序及多行文案粘贴。
- 本地视频导入、关联、解除关联、起点设置、缩略图和播放。
- 项目统一声音设置、逐行配音与试听、Codex 发起批量配音及失败项重试。
- 配音有效性、任务状态、修改权、项目锁和两端状态同步。
- 项目导出设置、全片粗剪导出、取消及中断恢复。

首版不包含完整电子表格、通用素材管理系统、图片生产流程、外部配音替换流程、场景／角色／标签管理、任意修改业务状态、多人协作、云同步、视频生成、自动视频匹配、口型处理、时间线编辑器、发布级特效、语音识别、逐字高亮字幕、多角色和逐句情绪。

不提供表格批量生成／批量重试按钮、配音取消按钮、历史配音版本切换或通用素材自动清理。不设置万级记录或数百 GB 素材的性能目标。

## 项目与口播片段

项目固定存放在当前工作空间根目录的 `clapgrid/` 子目录，归属规则见 [ADR0001](adr/0001-workspace-project-binding.md)。

默认每片段一句文案，也可以包含连续几句话。粘贴多行文案时，每个非空行创建一个片段。用户可手动调整片段顺序。

项目顺序决定成片顺序。表格筛选、勾选及视图排序不改变项目顺序。数字行号表示项目片段顺序，筛选后不重新编号；业务操作使用稳定身份，不以可变化的显示位置作为身份。

空项目可保存，不可导出。

## 本地文件与素材

导入的素材默认复制到项目。移除关联、替换关联或删除片段不删除原有素材文件。同一素材可复用，不引入通用自动清理。

本地文件访问限定在明确的项目和用户指定的导入来源。导入来源不必位于项目内，导入后使用项目内副本。密钥不属于项目素材。

单视频关联的规则：不可解码的视频拒绝关联；无效起点拒绝保存并保留原值。起点必须大于等于零且小于视频时长，不能等于视频结尾。导出前再次检查素材与起点，避免导入后文件损坏或丢失。视频默认静音原声，以对应配音时长决定片段时长：从指定起点开始截取，剩余视频过长时截断；剩余视频过短时冻结末帧补足并提示用户，不因此阻止导出；视频等比缩放并留边。

## 配音与统一声音

首版通过 TokenDance 调用 `seed-tts-2.0`。用户自备 API Key，文案发送给该在线服务，结果保存在本地。不自动切换供应商或模型。

音色和语速对整个项目生效，不提供逐片段覆盖；语速按供应商支持范围校验。音量固定默认值，不开放情绪、音调等高级参数。可选音色、默认值与语速范围见 README 的[单片段配音](../README.md#单片段配音)。

### 配音有效性

仅文案与声音输入变化影响配音有效性。画面素材关联、片段顺序、导出编码、帧率及字幕字体字号不影响配音有效性。

- 配音输入快照与当前输入一致：有效配音。
- 当前输入变化：保留旧配音，显示配音待更新，不自动生成。
- 输入改回且与保留配音的快照完全一致：恢复有效，无需重新生成。
- 重新生成成功且输入匹配：新结果成为当前配音。
- 重新生成失败：保留原配音及其有效性，单独显示任务失败。

配音可用性与最近任务状态分别展示。同一片段可以同时显示「有效配音」和「最近生成失败」。全部任务结束后，仍有效的旧配音可用于导出；待更新配音只能试听，不能导出。

### 文件保留与试听

每个片段最多保留三个生成音频文件。优先保留当前有效配音，其余按生成成功时间由新到旧保留；新生成失败不触发清理。该限制不清理导入素材，也不引入删除片段后的通用素材清理。

默认播放当前有效配音；没有有效配音时播放最新旧配音并标明待更新；没有音频则显示缺失。展开最多三个保留音频，显示生成时间与对应文案，可分别试听，不提供历史版本切换。

### 发起、失败与重试

每行提供生成／重新生成，以及失败或中断后的重试。Codex 可按明确指令处理指定片段、当前勾选、缺失或待更新片段，以及失败项。

批量中某片段失败不阻止其他片段继续。显示完成数和失败数，所有任务结束后才解除项目锁。不自动重试，也不自动补生成。

同一次操作使用固定请求标识；请求重发返回原结果或已有任务，不重复付费生成。用户主动再次点击或明确发出重新生成指令，才创建新操作。

「重试刚才失败的片段」限定在刚才那次操作；「重试项目里所有失败的片段」才覆盖全项目。已删除、已成功或正在生成的目标不重复提交，并说明原因。显式重试读取最新输入，不沿用失败任务的旧快照。

删除片段后，任何迟到结果不得恢复片段。正常配音期间项目已锁定，不能删除片段；迟到结果处理是保护规则，不构成允许生成中编辑的例外。

## 凭据与在线服务异常

密钥使用本机运行配置中的 `TOKENDANCE_KEY`，配置位置见 README 的[单片段配音](../README.md#单片段配音)。密钥不写入项目数据，不由表格或业务 MCP 回显。界面仅显示已配置／未配置；已配置不代表已验证服务可用。

缺少密钥时，在提交生成前拒绝请求，提示实际配置位置和键名，不发送付费请求。更换密钥不影响已有配音有效性。

鉴权失败、余额不足、限流和服务错误分别说明原因及下一步。已有配音保留，不自动重试。请求已发送但无法确认结果时，明确显示「结果未知，可能已计费」，由用户决定是否重试。局部返回的音频不能当作成功结果。

## 修改权与任务锁

同一时间仅允许表格用户或 Codex 一方修改项目。两端通过同一业务层执行规则。

| 状态 | 修改规则 | 允许的查看操作 |
| --- | --- | --- |
| 用户正在编辑 | 从进入编辑到保存或取消占用修改权；Codex 写请求立即被拒绝，不排队 | 查询与试听 |
| Codex 正在修改 | 从取得修改权后读取目标，到整批完成或失败；表格不能开始编辑 | 查询与试听 |
| 配音进行中 | 从提交前锁定项目，直至本次全部任务成功、失败或中断；不追加生成 | 查询、进度查看与试听 |
| 导出进行中 | 全程锁定项目，至成功、失败、中断或取消清理完成 | 查询、进度查看、试听与取消导出 |

Codex 的普通查询、思考和等待用户回答不占用修改权。普通编辑连接断开或异常时释放修改权。后台任务不会因表格或 Codex 关闭而解锁。

任务锁禁止修改文案、片段顺序、关联素材、视频起点、统一声音及导出设置，也禁止新增／删除片段和导入素材。同工作空间的多个对话共享修改权与任务锁，不同工作空间的锁互不影响。配音未全部结束时不能开始导出。

Codex 取得修改权后重新读取目标。若内容较此前普通查询已变化，返回变化信息，不按旧内容提交；已删除的目标跳过并说明。其他可处理目标正常处理，逐项返回结果。

## 表格与业务 MCP 的反馈

业务状态由系统计算，不提供任意修改状态的下拉菜单或 MCP 接口。接口不以通用单元格或素材 CRUD 替代业务约束；当前工具与参数见 README 的[业务 MCP 与插件](../README.md#业务-mcp-与插件)。

操作针对稳定片段身份。提交后固定目标集合，改变表格勾选不改变已提交任务。表格关闭或没有勾选时，「处理选中片段」返回无可用选择，不能扩大为全项目；按条件查询、指定片段和导出全片仍可用。

长任务先返回已受理及任务标识，再查询最终结果，不把已开始说成已完成。批量结果包含逐片段结果与汇总，区分已受理、已有任务、已跳过、被拒绝，以及最终成功、失败、已中断；导出另有取消清理反馈。

表格自动显示 Codex 修改和任务结果；Codex 查询读取相同项目状态。

## 字幕

字幕来自对应片段文案，整句同时显示，持续时间跟随该片段配音，并烧录进成片。允许自动换行、分成多行显示，不强制两行上限。

不提示文案过长，不建议用户拆分，不因文案过长阻止导出。是否修改文案或拆分片段由用户决定。系统不自动拆分口播片段，不增加逐字高亮或片段内分批字幕的时间对齐流程。

字幕字体、字号等导出设置的首次配置与作用范围见[全片导出设置](export-settings.md#首次配置与作用范围)。

## 全片导出

始终按项目片段顺序导出全片，筛选和勾选不改变范围。片段直接拼接，不添加转场或额外间隔。

导出前一次列出所有可检查的问题及对应片段或项目设置，包括：

- 空项目、缺失视频、素材不可读或不可解码、无效视频起点。
- 配音缺失或配音待更新。
- 字体／字号尚未设置，或导出设置不合法、当前环境无法使用。
- 配音任务尚未结束，或项目被其他修改操作占用。

校验失败不跳过片段、不使用待更新配音、不自动生成配音。短视频末帧冻结提示不阻止导出；长文案不提示、不阻止导出。

开始时确定本次完整内容、素材和导出设置，并锁定项目。每个项目同时只运行一个导出任务；重复请求展示已有任务，不新增排队任务。

成片保存在项目 `exports/` 目录，文件名包含时间与唯一标识。每次成功导出新文件，不覆盖已有成片。显示文件位置并提供打开入口。

提供取消导出。取消时显示清理状态，等待任务停止并清理本次临时文件后恢复编辑，不保留半成品。失败时显示原因，能定位到片段则指出片段；保留已有成片并清理本次未完成文件。

## 运行、保存与恢复

以具备右侧面板的 Codex 桌面端为交付对象。普通用户安装插件后，必须从 Codex 右侧打开表格；外部浏览器不能替代这一要求。

首次使用允许安装必要的本地组件。后续由 Codex 启动服务并打开表格，日常不要求用户手动打开终端或启动服务。宿主要求启动审批时遵守审批，不能绕过或把拒绝启动显示成成功。

每次完成编辑后自动保存，显示保存中／已保存／保存失败。保存失败不能显示已保存。重开恢复已保存内容，不承诺恢复尚未提交的单元格输入。

本地服务与 Codex 窗口生命周期分离。关闭表格或完全退出 Codex，已受理的配音与导出继续；重开连接已有项目及任务，不重复发起。项目固定绑定工作空间，不提供切换入口；工作空间识别、多对话共享、更换工作空间与旧项目迁入见 [ADR0001](adr/0001-workspace-project-binding.md)。

主动退出本地服务时，若有任务，提示并默认保持服务；只有明确选择「中断任务并退出」才停止。该流程不构成配音取消按钮。

服务退出、崩溃或关机后，重开保留已完成结果，未完成任务显示已中断，不自动重试。确认后台任务已终止并完成必要清理后解锁。导出中断清理本次半成品、保留已有成片；再次导出使用最新内容，从头开始，不做断点续导。

## 实现边界

采用 React、TypeScript、AG Grid Community、SQLite 及本地媒体处理。SQLite 保存结构化项目与任务状态，媒体文件单独保存在本地；表格不是数据源。UI 和 MCP 共用业务层，本地后台服务负责实际任务执行。

这些技术方向不能替代运行验证。精确数据库结构、工具 schema、安装分发方式、编码与帧率默认值和可选范围、字幕渲染布局、字体获取方式、字号单位等由开发设计与验证落实。

实现选择必须满足已确认的产品契约，不得降低三平台要求、改用外部浏览器交付、自动付费重试，或用增加提示／阻止导出改变长文案行为。若技术事实使契约无法满足，应带证据回到决策讨论。

以下为产品验收场景，执行记录与通过状态由 [#30](https://github.com/dulltackle/ClapGrid/issues/30) 汇总。主样例是一条含 20～30 个口播片段的项目，覆盖正常流程和局部修改后的再次制作。A03、A09、C02 按单视频关联编写。

### 正常制作与导出

| 编号 | 场景 | 可观察结果 |
| --- | --- | --- |
| A01 | 创建、打开与重开项目 | 指定本地文件夹；已保存的文案、顺序、素材、设置和状态恢复 |
| A02 | 粘贴含空行的文案 | 每个非空行创建一个片段；新增、删除、手动调整顺序可用 |
| A03 | 导入和复用视频 | 导入复制到项目；多个片段可关联同一素材；解除关联或删除片段保留素材 |
| A04 | 默认配音与统一设置 | 默认 vivi 2.0 原速；三种音色可选；音色和语速对全项目生效 |
| A05 | 单行及 Codex 批量配音 | 单行按钮和 Codex 指令可生成；表格没有批量生成／批量重试按钮 |
| A06 | 首次配置导出 | 编码、帧率有可修改默认值；字体、字号未设置；未完成必填项不能导出 |
| A07 | 设置保存与作用范围 | 用户设置后重开仍保留；修改导出设置不影响配音有效性；下一次成片采用新设置 |
| A08 | 全片顺序与范围 | 筛选或勾选部分片段后导出，仍包含项目顺序下的全片 |
| A09 | 视频长度及画面 | 指定起点生效；长视频截取、短视频冻结末帧并提示；等比缩放留边，原声默认静音 |
| A10 | 字幕 | 使用指定字体字号，自动换行并烧录，随配音整句显示；长文案不提示、不阻止导出、不自动拆片段 |

| A12 | 再次导出 | 生成不同文件，保留原成片，使用最新项目内容和设置 |

### 有效性、选择与互斥

| 编号 | 场景 | 可观察结果 |
| --- | --- | --- |
| B01 | 修改文案或声音后恢复原值 | 先显示配音待更新；改回与保留快照一致后恢复有效；不自动生成 |
| B02 | 重新生成失败 | 任务失败与旧配音有效同时可见；仍可试听，全部任务结束后可正常导出 |
| B03 | 配音待更新及历史试听 | 旧配音可试听、不可导出；最多三个音频，可辨认文案与时间，无版本切换入口 |
| B04 | 生成音频保留 | 新成功结果按规则保留最多三个；失败不清理；不清理导入视频 |
| B05 | 筛选、勾选及提交后改选 | 按稳定身份固定目标；数字行号按项目顺序；后续改选不影响任务 |
| B06 | 空选择或表格关闭 | 选中片段指令返回无可用选择，不扩大范围；明确条件查询及全片导出仍可用 |
| B07 | 两端普通修改竞争 | 用户编辑时 Codex 写入立即被拒绝；Codex 修改时表格不能编辑；结束或异常后释放修改权 |
| B08 | 查询后目标变化或删除 | 取得修改权后重读；返回变化信息，跳过已删除目标，不使用过时输入 |
| B09 | 配音任务锁 | 同工作空间各对话的两端编辑、设置修改、导入和追加生成均被拒绝；查询与试听可用；部分失败不影响其他任务，全部结束才解锁 |
| B10 | 导出任务锁 | 配音未结束不能导出；导出全程禁止修改项目和设置；清理完成前不解锁 |
| B11 | 请求重发与显式重试 | 同一请求返回已有结果／任务，不重复生成；新重试使用最新输入，按指定失败范围处理，不重做成功项 |
| B12 | 两端反馈 | 表格自动呈现 Codex 修改和任务状态；返回逐项结果与汇总，已受理不等于成功 |

### 无效输入、故障与恢复

| 编号 | 场景 | 可观察结果 |
| --- | --- | --- |
| C01 | 空项目 | 可保存，不可导出 |
| C02 | 无效媒体或起点 | 不可解码视频拒绝关联；负起点或起点达到／超过结尾拒绝保存并保留原值 |
| C03 | 导出前汇总校验 | 同时列出缺失／损坏视频、无效起点、缺失／待更新配音及无效设置，不跳片段、不自动配音 |
| C04 | 凭据缺失或更换 | 缺失时提示位置和键名，不发付费请求；更换密钥不影响已有配音；不回显密钥 |
| C05 | 服务错误及结果未知 | 鉴权、余额、限流、服务错误有原因和下一步；结果未知提示可能计费，不采用部分音频，无自动重试 |
| C06 | 重复导出和取消 | 重复请求返回当前任务；取消显示清理状态，清理后解锁，无本次半成品 |
| C07 | 导出失败 | 显示原因及可定位片段，清理本次未完成文件，保留已有成片并恢复编辑 |
| C08 | 保存失败 | 显示失败，不伪装为已保存；重开只承诺恢复已保存内容 |
| C09 | 关闭表格或完全退出 Codex | 配音和导出继续；重开显示同一任务进展／结果，无重复任务；后台锁不提前释放 |
| C10 | 主动退出服务 | 有任务时默认保持服务；明确中断退出后停止，重开显示已中断、保留已完成结果，无自动重试 |
| C11 | 服务崩溃或关机 | 恢复规则与中断一致；确认终止和清理后解锁；导出重试从头采用最新内容 |
| C12 | 三平台安装及启动 | 实际安装插件后均从 Codex 右侧进入；首次组件安装及失败反馈可用；日常无需手动终端，遵守宿主启动审批 |

## 开发门槛与交付门槛

允许在保留未验证项的前提下开发。规格和原型证据可以支撑开发，不代表三平台产品交付完成。交付要求三平台相关验证和上述产品验收全部通过。

未完成验证由 [#30 三平台端到端交付验收](https://github.com/dulltackle/ClapGrid/issues/30) 汇总，平台部分由 [#27 Windows](https://github.com/dulltackle/ClapGrid/issues/27)、[#28 macOS](https://github.com/dulltackle/ClapGrid/issues/28) 与 [#40 干净 Linux 首装](https://github.com/dulltackle/ClapGrid/issues/40) 承接，继续保持未验证状态；来源事项因归并关闭不等于验收通过。

若后续验证不满足既定边界，回到决策讨论；不因允许先开发而降低右侧面板、独立后台任务或三平台交付要求。
