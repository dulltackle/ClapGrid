# 面板亮色样式规范

本规范涵盖 #31、#32、#34、#35、#36、#37、#38、#39，固定参考 Codex 26.924.22138 默认亮色打包值。实际宿主截图比对状态见 `validation/issue-31/README.md`。样式在项目内维护，不读取安装目录、宿主主题或系统深浅色偏好。

## 语义变量

唯一来源为 `src/panel/style.css` 的 `:root`；AG Grid 通过 `themeQuartz.withParams` 引用相同变量。

| 用途 | 变量 / 规则 |
| --- | --- |
| 主表面、弱化区域 | `--color-surface` 白色；`--color-surface-subtle` 浅灰 |
| 正文、辅助文字 | `--color-ink` #1a1c1f；`--color-ink-secondary` |
| 强调、键盘焦点 | `--color-accent` #339cff；`--color-focus` 深蓝，保证白底可见 |
| 分隔线、悬停 | `--color-border`；`--color-hover` |
| 错误文字、错误背景 | `--color-error`；`--color-error-surface`，同时提供文字说明 |
| 字体 | `--font-ui` 系统字体栈，正文 14px，辅助文字 12px，标题 18px / 600 |
| 间距 | 4px 基础单位：`--space-1/2/3/4/6` 对应 4/8/12/16/24px |
| 圆角 | `--radius-control` 6px；`--radius-panel` 8px |

## 使用规则

### 整体验收（#34）

#35–#39 已实现浮层、布局、全文编辑、条件批量操作及紧凑单元格。整合后的真实浏览器回归、当前 Codex 宽窄宿主截图及逐条验收映射见 [#34 验证记录](validation/issue-34/README.md)。各子事项记录保留历史实现过程，当前布局以本轮证据为准。

### 表格信息组织

- 表格以文案为中心，画面素材和配音紧随其后，画面说明位于最末尾。
- 五列表头顺序为序号、文案、画面素材、配音、画面说明。当前已支持文案编辑、本地视频导入／关联／预览、配音生成／试听／保留音频和全片导出；画面说明仍无编辑能力。
- 下表描述当前界面能力。#31、#32 截图保留为历史证据，主视图布局见 [#36 验证记录](validation/issue-36/README.md)，文案与行高见 [#37 验证记录](validation/issue-37/README.md)。

| 表头 | 含义与展示 |
| --- | --- |
| 序号 | 项目中口播片段的播放顺序，查找及显示排序后保留原编号 |
| 文案 | 待朗读的文字，也是字幕的默认文字来源；浏览时最多显示三行，进入编辑可处理全文 |
| 画面素材 | 当前支持关联一份本地视频；单元格展示缩略图、省略的简短名称与详情入口；只读详情展示完整名称、时长与起点，并提供更改关联及起点入口 |
| 配音 | 集中展示配音可用性、最近生成情况及相关操作；例如有效配音与最近生成失败必须可同时表达 |
| 画面说明 | 保留末列，目前不提供编辑控件；未来用于记录作用于整行的可选说明 |

- 多素材混排、图片支持、素材顺序与时长分配属于后续能力，当前界面不暗示已经支持。
- 取消独立的“视频起点”列，在对应视频素材详情中设置源视频播放起点。
- 取消独立的“任务状态”列，行内配音任务信息纳入“配音”列；整片导出进度放在表格外的项目区域。
- 画面说明不自动转成导出设置。用户要求 Codex 按说明调整时，应转成明确的素材顺序、时长等设置。
- 待后续设计：多份素材的时长分配、与配音时长的匹配规则，以及素材详情交互；本次表头确认未决定这些规则。

### 布局与交互

- 页面留白宽屏上下 12px、左右 16px，600px 以下 8px；避免添加独立品牌色、装饰徽章和工程占位文案。
- 表头高度 40px，片段行高 80px，字号 14px，间距基础单位为 4px。文案按 22px 行距显示最多三行并垂直居中，短文案按实际内容显示；摘要仅作视觉省略，不截断数据或全文编辑内容。文案列 `flex: 1` 且最小 200px，其余列固定初始宽度、允许调整；素材初始 230px（最小 180px），配音初始及最小 290px，文案优先获得剩余空间。
- 容器保持 `min-width: 0`，由 AG Grid 自身承担横向滚动，不通过隐藏业务列适应窄屏。
- 连接提示持续可见；初次请求期间显示连接中，失败显示错误及读取失败提示，成功且无片段才显示空态。
- 路径、服务实例、PID 由底部「连接诊断」打开临时浮层；长文本使用 `overflow-wrap: anywhere`。
- 交互控件使用悬停、按下和 `:focus-visible` 状态；键盘焦点为 2px 深蓝轮廓。保留表格原生键盘导航和焦点样式。
- 只为现有控件定义规则。新增组件应复用语义变量，不提前制作无功能控件。

### 详情浮层（#35）

- 素材关联与起点调整、导入本地视频、视频预览、配音试听、保留音频、全片导出设置共用原生模态对话框。每个浮层具有可访问名称和可见的关闭或取消按钮，遮罩不承担关闭操作。
- 打开后焦点进入浮层；Tab 和 Shift+Tab 在当前浮层内循环，背景不能获得键盘焦点。媒体原生播放控件保留自身的键盘导航；保存导致全部控件禁用时，浮层本身仍可获得焦点。
- Esc 与可见的关闭／取消按钮使用同一业务流程。导出设置保存期间禁止关闭；字号草稿未提交时保留输入并提示先完成保存。素材处理仍允许现有的取消操作，继续中止请求、释放修改权和隔离迟到响应。
- 关闭后，页头入口恢复焦点；表格入口按片段稳定 ID 与原列恢复到单元格，避免轮询重建按钮后失焦。原片段删除时，回到相近的可见行；无可见行时回到常驻查找按钮。正常返回不改变横纵滚动位置，目标被虚拟滚动移出或合法重排到视口外缓冲行时才定位到对应行列。
- 素材和配音单元格内，Tab 可进入操作按钮，Enter／空格激活按钮；离开末个按钮后继续表格导航。
- 查看详情和在详情间切换不清除查找关键词、勾选，不提交编辑或创建配音、导出任务。修改仍由既有编辑仲裁与服务契约管理。
- 浮层最大宽度 680px，距窄视口边缘至少 16px，高度限制在动态视口内；长内容在浮层内部滚动，长文本换行。继续使用亮色语义变量和焦点样式。
- 宽视口、420px 浏览器窄视口及 Codex 内置浏览器 420×720 宿主补验的交互和布局证据见 [#35 验证记录](validation/issue-35/README.md)。外部浏览器窄视口与实际宿主验证分别记录。

### 紧凑主视图与低频入口（#36）

- 顶部常驻标题、新增口播片段、导出全片及「更多」；旁边的范围说明明确查找与勾选不改变全片导出范围。查找按钮常驻；片段组织工具栏按勾选状态显示批量操作，规则见 #38。
- 页面占满动态视口，以纵向弹性布局分配真实剩余空间，不使用固定视口减值或最小表格高度挤出整页滚动。多片段由表格内部纵向滚动，窄面板由表格内部横向滚动，保留五列及列宽调整。
- 「更多」提供导入本地视频、粘贴多行文案、声音设置、导出设置和任务记录。各入口保留原来的禁用条件；表单沿用即时保存、提交、取消及修改权规则。
- 这些详情均复用 #35 的模态层及焦点恢复；关闭后回到「更多」或实际状态入口。打开详情不改变表格位置及可用高度，不增加侧栏。导入时的编辑状态使用底部预留状态行，不改变布局。
- 底部持续显示服务连接、保存状态、项目锁定／修改状态及简短任务摘要。任务记录展示配音任务、批量进度、导出进度、错误、请求和任务标识，以及取消、打开成片、下载入口。
- 保存失败、断线、勾选同步异常、任务失败及结果未知且可能已计费等异常持续可见；即使对应片段未匹配查找也仍显示项目级提示。异常较多时在底部异常区域内部滚动，可随时主动查看详情，不自动弹层或抢走焦点。
- 导出轮询和操作错误归主视图生命周期管理；关闭详情不停止轮询，也不清空状态。恢复连接只清除连接错误；明确的新操作沿用原有错误生命周期。设置保存失败回传到持续状态栏，重新查看设置不会将它清除。
- 初次加载、读取失败及成功后的空项目使用不同提示；失败恢复为空项目时及时更新表格空态。

### 长文案摘要与全文编辑（#37）

- 双击文案或沿用 Enter、F2、字符键入口，在取得现有修改权后打开全文文本框。编辑器有「文案全文」可访问名称和键盘提示；显示宽度最多 560px，并受视口约束，高度最多 240px，长内容在文本框内部滚动。编辑器不新增字符长度上限。
- Enter 保存、Esc 取消；Tab 和失焦继续结束编辑并保存。Shift+Enter 插入换行，方向键、Home／End 用于文本导航，输入法组词期间的按键不交给表格提交。浏览态保持原生表格键盘导航。
- 全文编辑器只向 AG Grid 提供输入值，继续通过原有编辑请求与编辑会话保存，不增加手动保存按钮或新的提交接口。Esc 或断线关闭引发的失焦不重新提交取消的内容。
- 文案编辑期间保留修改互斥、重复请求保护和轮询仲裁；断线取消未提交草稿，单次保存的连接先关闭时继续等待请求结果。保存失败仍由底部状态栏持续提示。
- 窄面板保留五列和内部横向滚动；全文编辑器可超出文案列宽，定位在视口内，不挤动表格行。宽视口和 Codex 窄面板的浏览、编辑截图及交互结果见 [#37 验证记录](validation/issue-37/README.md)。

### 条件批量操作（#38）

- 查找按钮始终显示。只有存在勾选片段时，才显示勾选数量、删除勾选、项目顺序上移／下移；全部取消或勾选连接断开清空选择后收起。
- 数量统计全部勾选片段。查找保留全部片段且不改变勾选；表头复选框作用于全部片段。删除包含所有勾选片段，不能用可见行代替操作范围。
- 顺序调整要求单选，沿用编辑、修改权和任务锁定条件；边界和交换对象以完整项目顺序为准，不以查找结果或显示排序为准。序号仍表示项目播放顺序。
- 断线、同步失败及「重新连接勾选」保留在底部异常区域，不随批量操作收起。恢复连接沿用清空勾选、重新选择的规则。
- 工具栏沿用弹性换行和现有间距，不挤出页面横向滚动；表格继续占据剩余高度。宽屏、420px 浏览器和 Codex 窄面板的有／无勾选证据见 [#38 验证记录](validation/issue-38/README.md)。

### 素材与配音紧凑单元格（#39）

- 素材缩略图仍可直接预览；「详情」只读展示完整名称、时长和播放起点，不申请修改权。详情内「关联／更改」才进入原有素材编辑，可保存、取消、解除关联及调整起点；返回时先恢复详情，关闭详情后恢复原素材单元格。
- 配音在 80px 行内按可用性、最近任务、操作组织。有效配音、配音待更新、配音缺失与任务状态独立；最近任务的已受理、生成中、生成失败和结果未知且可能已计费均完整可见，失败／未知用错误色辅助表达，不靠悬停解释。成功时省去冗余成功说明。
- 高频生成／重新生成／重试及试听常驻，沿用原有禁用条件和请求标识保护。「详情」在没有保留音频时也可打开，展示任务完整说明、任务与请求标识，以及保留音频的时间、输入文案和可用性；只查看不会提交修改或生成任务。
- 待更新音频在单元格试听按钮、试听浮层和历史条目中都有明确说明。配音列最小宽度保障异常说明和操作完整可见；窄面板通过表格内部横向滚动访问所有业务列。
- 仍只支持单份本地视频，未提供多素材编排或画面说明编辑。宽视口、窄视口及 Codex 宿主证据见 [#39 验证记录](validation/issue-39/README.md)。

## 文案查找（#61）

- 表格右上方的「查找」按钮打开非模态浮窗；浮窗打开时表格仍可滚动、勾选、编辑，点击外部不关闭。关闭按钮及查找框内 Esc 关闭并清除高亮。
- 只在文案中按完整输入连续匹配，忽略英文大小写，保留空格，不匹配序号。每个匹配片段只计数一次，片段内全部出现位置高亮。
- 上一个／下一个按当前表格显示顺序循环定位，不修改项目顺序或勾选。当前长文案临时展开并滚动到命中；离开或关闭查找后恢复摘要。
- 编辑和删除后刷新匹配结果，不抢编辑焦点、不自动定位。当前命中失效后等待用户点击下一个；无结果显示「无匹配片段」。
- 关键词仅保存在当前面板内存中：关闭、重开查找恢复关键词，页面刷新清空，不跨面板共享。
