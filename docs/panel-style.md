# 面板亮色样式规范

固定参考 Codex 26.924.22138 默认亮色打包值。样式在项目内维护，不读取安装目录、宿主主题或系统深浅色偏好。语义变量唯一来源为 `src/panel/style.css` 的 `:root`，AG Grid 通过 `themeQuartz.withParams` 引用相同变量；组件与样式归属见[统一组件维护](ui-components.md)。

## 表格信息组织

- 表格以文案为中心；序号始终表示项目播放顺序，查找只高亮和定位，不改变顺序或勾选。
- 点击文案后在原位置编辑，保留行高、配音控件、缩略图及画面说明；输入框右上角内置“取消修改”“保存修改”“放大编辑”。放大和缩小共享草稿及光标位置，不提交、不重新申请修改权。Enter 换行，Ctrl／⌘+Enter 保存；原位 Esc 取消，放大视图 Esc 缩小。离开原位编辑区或 Tab 沿用失焦保存，操作按钮内部焦点切换和放大视图不提前提交。
- 画面说明是针对整个片段的可选画面要求，含义见 GLOSSARY.md，供用户和 Codex 参考。保存说明不改变素材、配音、字幕或导出结果，也不自动转成导出设置；用户要求 Codex 按说明调整时，应转成明确的素材顺序、时长等设置。
- 多素材混排、图片支持、素材顺序与时长分配属于后续能力，界面不暗示已经支持。多份素材的时长分配、与配音时长的匹配规则及素材详情交互尚未确定。

## 设计原则

- 避免独立品牌色、装饰徽章和工程占位文案；新增组件复用语义变量，只为现有控件定义规则，不提前制作无功能控件。
- 窄面板由表格内部滚动，不通过隐藏业务内容适应窄屏；打开详情或查找不改变表格几何。
- 保存失败、断线、任务失败及结果未知且可能已计费等异常持续可见，不靠悬停解释，不自动弹层或抢走焦点。
- 查看详情不提交修改、不创建配音或导出任务；修改仍由既有编辑仲裁与服务契约管理。
- 键盘焦点始终可见；浮层关闭后焦点回到稳定片段身份对应的入口，而不是易被虚拟滚动重建的旧节点。
