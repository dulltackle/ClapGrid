# 面板亮色样式规范

固定参考 Codex 26.924.22138 默认亮色打包值。样式在项目内维护，不读取安装目录、宿主主题或系统深浅色偏好。语义变量唯一来源为 `src/panel/style.css` 的 `:root`，AG Grid 通过 `themeQuartz.withParams` 引用相同变量；组件与样式归属见[统一组件维护](ui-components.md)。

## 表格信息组织

- 表格以文案为中心；序号始终表示项目播放顺序，查找只高亮和定位，不改变顺序或勾选。
- 双击文案或在阅读位置按 Enter / F2 后在原位置编辑，保留行高、配音控件、素材入口及画面说明；输入框右上角内置“取消修改”“保存修改”“放大编辑”。放大和缩小共享草稿及光标位置，不提交、不重新申请修改权。Enter 换行，Ctrl／⌘+Enter 保存；原位 Esc 在内容未改时结束编辑，已改时先提示放弃；放大视图 Esc 缩小。失焦、Tab、勾选、打开菜单、查看说明和试听保留草稿，不自动提交。切换片段或在文案与画面说明之间切换编辑位置时先保存，失败保留内容及原位置。
- 画面说明是针对整个片段的可选画面要求，含义见 GLOSSARY.md，供用户和 Codex 参考。保存说明不自动改写素材或编排；已有合成预览标记待更新，agent 按新说明更新明确编排。
- 每句画面素材按需展开行内托盘，收起显示数量；托盘只呈现本句确认使用的图片和视频，支持添加、查看原件和移出。编排由 agent 完成，用户不编辑位置、图层和时间；片段合成预览与单素材原件查看明确区分。

## 设计原则

- 避免独立品牌色、装饰徽章和工程占位文案；新增组件复用语义变量，只为现有控件定义规则，不提前制作无功能控件。
- 窄面板由表格内部滚动，不通过隐藏业务内容适应窄屏；打开说明或查找不改变表格几何。
- 保存失败、断线、任务失败及结果未知且可能已计费等异常持续可见，不靠悬停解释，不自动弹层或抢走焦点。
- 勾选范围、编辑目标和焦点独立。阅读、复制与聚焦不申请修改权；明确编辑入口才开始编辑。画面说明摘要负责展开，展开区原位编辑；画面素材与配音分别承载本区动作，行尾常驻本行菜单与拖动手柄，勾选数量、清空与批量删除入口持续可见。
- 右键、拖动已勾选片段作用于勾选集合，未勾选片段只作用于本行；菜单标明范围，拖动标明数量和落点，两者不隐式改勾选。取消拖动或删除确认不保存草稿；确认项目修改后先保存并交接修改权，仍遵循既有任务锁、冲突及配音契约。
- Esc 由焦点所在最内层处理，普通表格保持勾选；输入法选词交给输入法，保存中等待实际请求结果，不能表示为已撤销。
- 键盘焦点始终可见；浮层关闭后焦点回到稳定片段身份对应的入口，而不是易被虚拟滚动重建的旧节点。
