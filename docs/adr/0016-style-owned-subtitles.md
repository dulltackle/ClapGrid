# 字幕由项目风格绘制，不保留导出烧录

日期：2026-11-07

状态：已采纳（[#292](https://github.com/dulltackle/ClapGrid/issues/292)）。取代 [ADR0015](0015-page-rendering.md) 中“字幕继续统一用 ASS 烧录”一句；修订 [ADR0012](0012-user-linux-components.md) 的字体枚举与中文字幕导出验收。

## 决策

字幕的外观与出场方式属于风格，与画面统一。每个风格必须提供字幕绘制模块和固定的字幕保留区，缺少时拒绝导入。字幕的文字来自文案、时间来自片段，风格和页面都不定义字幕内容。

一个项目只有一个项目风格，保存在 ClapGrid 项目状态中。ClapGrid 为每个口播片段用项目风格的字幕模块单独渲染一层透明字幕层，叠在画面编排最上层；无页面的片段同样有字幕。只改文案时只重渲字幕层。页面统一经稳定路径 `/style/` 引用项目风格，不再在 `page.json` 中声明风格身份；预览的内容身份计入项目风格身份，改换或重新导入风格后预览与字幕层待更新。

不保留 ASS 烧录兜底。导出设置删除字幕字体和字号；未设置项目风格的项目可以编辑与预览（无字幕并提示），但不能导出。项目格式升版本，旧格式项目拒绝打开，不迁移、不删除用户文件。

## 否决的方案

- **页面各自绘制字幕**（lemo-opuscar 的做法）：opuscar 一部片子就是一个页面，ClapGrid 是多个片段各有页面，还存在无页面的片段。各页自画会让字幕在片段间漂移、无页面片段没有字幕，文案改动也要改页面代码，失去“文案是字幕来源”。
- **扩展导出设置的颜色、描边、位置**：只能对齐颜色和字体，做不到风格的质感与出场方式。
- **保留 ASS 烧录作为无风格项目的兜底**：会留下两套字幕外观与两套自检口径，违背“所有字幕与风格统一”。
- **页面继续用 `/styles/<styleId>/` 声明风格，只校验与项目风格一致**：每次修改风格都要改写全部页面路径。旧写法不再兼容。

## 后果

- 每次导出都需要浏览器组件。浏览器组件在 macOS、Windows 交付前，这两个平台不能导出；当前只保证 Linux。
- `fc-list` 不再用于导出设置和字幕；用户目录字体组件仍作为页面渲染的中文后备字体保留。ADR0012 中“用户目录字体枚举和中文字幕导出”的验收，改为验收页面后备字体可用与带风格字幕的导出。
- 页面画面自检判断“压字幕”改用风格声明的字幕保留区，不再按字体字号计算字幕框。
