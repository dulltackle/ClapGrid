# 外围控件采用 shadcn/ui 与 Tailwind CSS，保留 AG Grid

2026-10-07，用户确认引入组件库以减少通用控件维护并统一交互，优先级为维护成本、依赖与产物体积、视觉简洁。用户随后明确将最初的直接采用 Base UI 与手写样式方案调整为 shadcn/ui + Tailwind CSS；本记录以调整后的决定为准。

按需引入 shadcn/ui 组件源码，通过统一的项目内组件入口使用，由项目维护必要的业务适配并审阅后续上游更新。采用现成组件和标准样式约定帮助 AI 遵循统一模式，同时接受本地组件源码的维护责任。底层原语沿用所选官方组件模板的一致路线，实施时记录来源与版本，不另行建设基础交互库。

“对 AI 友好”同时涵盖便于 AI 编码和便于 AI 操作页面，以统一组件接口帮助 AI 修改代码为主，兼顾语义、可访问名称和键盘操作。这是界面实现约束，不是产品领域术语。

Tailwind CSS 接入现有 Vite 构建，将现有 CSS 语义变量映射到组件主题，保持亮色视觉方向；AG Grid 继续负责口播片段表格。保留非试点区域所需样式，核对基础样式及层叠对表格和未迁移控件的影响。产物轻量与否以试点前后生产构建测量为准。

页面布局与业务组件样式采用 Tailwind，通用控件采用统一入口的 shadcn/ui 组件；CSS 文件仅保留主题变量、基础样式和必要的第三方适配。扩展工具类扫描范围时逐批移除旧业务类名，避免保留两套布局样式。最终启用 Tailwind Preflight，在统一基础样式的批次集中切换并进行全页面回归；显式补齐标题、段落、列表、链接、媒体及原生控件样式，保持既定视觉方向。

所有项目自有静态样式均纳入重写；保留 AG Grid 官方主题机制和浏览器原生媒体控件内部样式。AG Grid 的项目配置与覆盖规则仍须审查并统一到共享主题变量，查找展开高度和拖动指示位置等运行时测量继续使用动态样式。全站重写不以消除全部 CSS 或动态内联样式为目标。

批次之间允许新旧实现暂时共存；迁移收尾时清理范围内承担相同职责的旧通用组件与失去用途的样式，必要例外逐项记录，避免长期维护两套实现。

业务继续拥有保存、取消、关闭限制和修改权规则，组件接管通用交互；保留各流程不同的关闭语义、嵌套返回和稳定片段焦点恢复。原生音视频播放控件、文件选择和原生选择器行为，以及 AG Grid 文案编辑器、拖动手柄的专用交互，作为明确例外保留；普通按钮和输入通过统一入口使用组件，缩略图与拖动手柄只复用适用的样式和可访问语义，不强制采用普通 Button 尺寸。保留这些交互不豁免项目自有样式的重写。

迁移按完整用户操作流程分批验证：先页头与查找、“更多”、任务记录和连接诊断，再声音设置与粘贴多行文案，随后配音试听、画面素材及关联视频、导入和预览的嵌套流程，最后表格内自定义操作控件及旧 Dialog、无用样式清理。各流程批次同时重写对应业务样式，Preflight 的集中切换须覆盖全页面及尚未迁移区域，不能依靠后续批次修复已引入的视觉回归。各批次进行源码验证，最终统一完成正式验收、本机插件更新及实际宿主验收，分别报告源码、安装包和实际宿主状态；如需手动重载则明确保留待办。
