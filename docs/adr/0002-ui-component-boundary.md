# 外围控件采用 shadcn/ui 与 Tailwind CSS，保留 AG Grid

2026-10-07，用户确认引入组件库以减少通用控件维护并统一交互，优先级为维护成本、依赖与产物体积、视觉简洁。用户随后明确将最初的直接采用 Base UI 与手写样式方案调整为 shadcn/ui + Tailwind CSS；本记录以调整后的决定为准。

按需引入 shadcn/ui 组件源码，通过统一的项目内组件入口使用，由项目维护必要的业务适配并审阅后续上游更新。采用现成组件和标准样式约定帮助 AI 遵循统一模式，同时接受本地组件源码的维护责任。底层原语沿用所选官方组件模板的一致路线，实施时记录来源与版本，不另行建设基础交互库。

“对 AI 友好”同时涵盖便于 AI 编码和便于 AI 操作页面，以统一组件接口帮助 AI 修改代码为主，兼顾语义、可访问名称和键盘操作。这是界面实现约束，不是产品领域术语。

Tailwind CSS 接入现有 Vite 构建，将现有 CSS 语义变量映射到组件主题，保持亮色视觉方向；AG Grid 继续负责口播片段表格。保留非试点区域所需样式，核对基础样式及层叠对表格和未迁移控件的影响。产物轻量与否以试点前后生产构建测量为准。

首批仅迁移“行菜单 → 删除确认弹窗 → 操作完成后恢复焦点”的完整操作链及其中的按钮。验收覆盖键盘操作、嵌套交互、任务锁导致的禁用和表格焦点恢复；验证后再决定是否推广至设置表单等外围区域。保留现有视觉方向，统一控件细节。

用户已确认复用现有浏览器集成测试边界；该测试的独立打包流程也须加载正确的 Tailwind 样式。实施规格见 [#74](https://github.com/dulltackle/ClapGrid/issues/74)。本记录不表示已安装依赖、完成迁移或通过实际宿主验收。
