# 面板定位为审阅与决策台，退役画面说明

日期：2026-11-09

右侧面板只承载用户需要管理和判断的内容：文案、画面素材、配音是否有效、片段合成预览是否就绪，以及需要用户决定的异常。素材编排和任务执行交给 Codex，面板只呈现结果。状态采用“正常即沉默”：连接正常、已保存、勾选为空等状态不常驻显示，只在出现异常、需要用户行动或有内容可操作时才出现；项目信息与项目风格提示例外，保持常驻。

在这一定位下，**画面说明**整体退役，不再只是从面板隐藏。面板、业务 MCP 参数、数据契约和术语表中都不再有它，已有字段通过迁移删除，`visualVersion` 改为不含说明的新格式。退役的原因有两点：画面要求已由制作卡和页面承载，形成了重复；用户可以直接通过对话请 Codex 修改片段。另一个备选方案是保留一个只有 Codex 读写、用户看不到的字段，但这又会形成与制作卡重复的第二个来源，因此没有采用。

请求标识、操作标识、PID、服务实例、版本指纹等工程标识，不再在面板上显示，诊断交由 Codex 通过业务 MCP 进行。`docs/panel-style.md` 中的交互细节与代码、测试重复，因此删除该文件；其中从代码看不出来的原则并入 `docs/ui-components.md`。

## Consequences

- 本决定部分取代 [ADR0014](0014-row-owned-segment-actions.md)：画面说明不再是行内区域，原位编辑和草稿过程只用于文案。
- 迁移后，所有已有的片段合成预览都会一次性标记为待更新，需要 Codex 重新制作。这是有意为之：不为旧哈希保留兼容代码。
- 写过画面说明的旧项目，迁移后这些说明不再保留。
