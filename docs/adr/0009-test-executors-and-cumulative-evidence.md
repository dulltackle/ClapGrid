# 测试执行者试点与同次累计证据

2026-10-16，用户在 [#148](https://github.com/dulltackle/ClapGrid/issues/148) 确认以下设计。沿用 ADR 0003 的固定提交证据边界、ADR 0006 的强制预检与集中失败复验，以及 ADR 0008 的真实浏览器和后台任务生命周期保障。本记录确认设计采纳；实现完成、性能达标、固定提交正式验收、本机安装和实际宿主交付分别需要实际证据。

## 决定

首轮仅迁移已确认的 16 项逻辑、4 项真实 HTTP/SQLite 集成和 14 项 UI 固定核心场景；其中 UI 的样式碰撞有 2 项，真实浏览器有 12 项。候选直接开发依赖固定为 Vitest 5.0.5 与 Playwright Test 1.64.1，并提交锁文件。Vitest 使用 Node 环境，Playwright Test 保持原生键鼠、真实 AG Grid 与生产同源 CSS；生命周期、取消、验收任务及未迁移测试继续使用 Node 原生测试器。清单明确唯一执行者、预检及完整范围；单独保留原生对照实现与逐场景映射，不在常规完整检查重复调度。

新增日常入口默认单次执行，显示选择范围、依据、未覆盖项；watch 仅显式开启。静态导入关系只是选择依据之一；字符串浏览器脚本、文件读取、子进程、CSS、配置、helper 与打包输入使用显式映射，无法可靠判断时扩大范围。零收集不能视为通过，局部通过不能升级成完整验收。

保留预检先执行及失败阻塞。同一运行中，实际通过、源码/配置/环境身份一致的预检文件和类型检查可计入完整覆盖，后续仅执行剩余集合；聚合记录必须引用原证据，不伪装成再次执行。不同运行及历史成功不能自动累计。每个执行者保存可读日志与原生报告，统一记录预期/实际文件及用例、逐项状态、失败位置、起止时间、执行者版本及来源。缺报告、收集失败、未捕获错误、取消、身份/集合不符和不完整执行均失败；UI 缺浏览器、跳过或 todo 仍不能通过，其他范围沿用既有政策。正式验收与显式历史复用使用相同校验。

浏览器进程可按 worker 复用，每例独立 context、页面、临时目录及所需后端/SQLite/端口；业务替身保持既有 HTTP 客户端边界。分别测量并发 1 与 2 后再选择默认值；共享资源及生命周期专项保持串行，不通过取消隔离或自动重试掩盖失败。允许复用输入可验证的编译产物，输入含源码、锁定依赖、配置、资源、构建选项与工具版本；未知或损坏缓存重新构建，命中后仍实际测试。

新执行者、worker、浏览器与 watch 均纳入现有工作树锁及登记范围；显式取消由实际拥有者完成，全部本次进程退出后才释放锁。保留同身份正式验收连接、观察者退出不中止任务、异常退出保守处理及其他工作树不受影响。固定提交验收继续独立检出、`npm ci`、完整类型检查/测试/生产构建及源码变化检查。

## 验证与推广边界

以真实命令、隔离小仓库、真实子进程和报告故障注入验证上述约定。保留业务输入输出、真实 HTTP/SQLite 和真实浏览器外部行为断言。原生/候选在同机、固定试点源码、相同行为覆盖下各至少执行三次，记录冷/热缓存、并发、环境、准备/交互/清理及端到端时间，取中位数：逻辑 ≤1.5 秒，HTTP/SQLite ≤2.5 秒，UI 固定核心完整入口（含类型、测试、构建及清理）≤35 秒。UI 对照采用既有并发 2；并行场景累计时间不能当作 wall-clock 占比，长期 watch 重跑不能替代单次预算。

先交付报告与执行清单，再逐组迁移、累计覆盖/生命周期回归、性能对照及固定提交完整验收。预算不达标时保留原有通过路径、定位和优化，不扩大迁移。当前不承诺全套加速比例，也不一次性迁移全部测试、不新增模拟 DOM 体系、不改变产品业务、不自动安装/更新插件或合并/发布。

## 取舍

引入两个执行者及适配层增加维护成本，换取逻辑反馈、浏览器准备复用和定向检查能力；显式清单与逐项证据防止迁移漏跑。设计采纳不保证这些收益已经实现。运行命令、证据格式与当前阶段见 [检查与正式验收](../agents/verification.md)。

### 启动与准备成本的优化边界（#156）

用版本化完整内容身份和短期线程分摊当前读取，保留全部代码检查输入；2026-10-17 按 [ADR0010](0010-code-check-input-boundary.md) 排除独立制作工程和历史产物，原“全部原输入”不再包含这些历史目录。默认 4、API 上限 8 的选择兼顾线程启动、CPU/内存及磁盘竞争。纯 Vitest 框架准备可与读取重叠，项目代码仍在本次身份完成后执行；历史目标保留旧协议和身份形状。

只对已确认隔离的 segment、table、wide 文件内并行，speech/CSS 保持串行；CSS 共用 worker pool 而不创建浏览器。每例隔离、真实键鼠、原脚本/等待/断言和零重试保持原决定。开发 JS 压缩保留名称、CSS 工具延迟到 miss 真实编译，减少准备成本；缓存仍按完整当前输入核对。

读取复用限于同一连续同步、封闭只读边界，准确前缀状态继续消费原连续 SHA 字节流，不跨 await/view 使用历史字节。未采用通用历史投影 LRU 或已载工具快照：当前工具集合的复制/驻留成本及与前缀复用的抵消作用，不足以用组件差值证明完整 helper 收益。

Node 字节码自动默认限于单次受控测试 child，watch 派生链关闭该默认，显式控件保留；正式独立检出按实际目标派生。缓存命中始终只是编译准备复用，真实执行、同次累计及历史成功复用各自保留原证据条件。

取消先通过实际组归属与完整拥有者绑定确认的控制通道请求合作收尾，再沿原进程组边界兜底；轮末资源清理前确认全部本次登记组已退出。未知/变化的拥有权保留现场，清理期间仍处理取消信号。该协议不根据目录名或不可见 PID 推断其他任务已结束。

这些选择增加身份协议和实现审查成本，需以真实进程、helper、报告及故障反例验证。原覆盖与预算不变，样本或组件下降不等于完整入口达标；性能方法、协议与交付边界见 [试点记录](../research/test-executor-pilot.md)。

### PR 全量检查优化的后续决定

2026-10-17，用户针对 PR #160 的实际检查耗时确认：每个 PR 继续执行全量测试，不将检查工具、watch、生命周期或验收系统自身的专项后移到合并后。自动检查只保留 `pull_request` 和 `main` 分支的 `push`，保留手动入口；功能分支不再因 `push` 额外执行一套检查，尚未创建 PR 的功能分支不取得自动检查证据。PR 仍验证合并结果，main push 验证 main 提交，不跨事件自动复用通过记录。

后续优化重点是充分利用 Vitest 和 Playwright，允许按实际热点逐组扩大迁移，替代本记录首轮“性能预算未达标不扩大迁移”的推广限制。每个场景的行为覆盖、真实浏览器执行、隔离、零重试、取消清理和原始证据要求继续保留；扩大迁移不意味着所有真实进程专项必须更换执行者。优先缩短等待完整检查结果的时间，同时约束总 runner 成本。本轮不预设耗时目标，以实际优化前后测量判断收益；既有试点的历史性能缺口不因此改记为达标。

用户进一步确认允许精简甚至移除自研测试执行层，充分使用 Vitest 和 Playwright 原生的收集、调度、隔离、浏览器复用及报告能力；必须保留全量行为覆盖和必要验证保障。现有执行层结构不再是必须保留的约束，删除或替换前须证明完整性核对、失败反馈、固定提交来源及取消清理仍可靠。项目特有且框架不能直接提供的保障可保留最小适配，不以原生退出码代替完整验收。

本段记录已确认的设计方向，不表示工作流或测试迁移已经实现。实施规格见 [#161](https://github.com/dulltackle/ClapGrid/issues/161)；实现、性能测量和固定提交完整验收分别提供证据。

## 全量原生调度收口（#171）

常规清单110文件由38 Playwright、18 Vitest和54 Node唯一承接，预检范围不变，历史对照仅comparison-only。Playwright沿原文件级模式使用原生worker池，每例仍隔离context/page/目录与资源端口；普通test-runner默认请求2，显式--concurrency 1保留。UI快检/相关入口继续执行计划器的maxConcurrency，不将非静态或未知范围自动提升为并发2；Node生命周期/共享环境专项与Vitest服务保持原有串行/isolate边界。没有增加机器或分片。

废弃checkBrowser的dumpDOM启动/独立构建路径已无调用者并删除；Chrome发现及四个历史原生对照使用的interactive-browser保留。已删除的重复报告、MemoryBuildCache和内部冗余对照与替代保障见[最终职责/完整范围/测量材料](../research/native-scheduling-171/README.md)。自研只保留唯一归属、严格UI、源码/环境身份、原始报告完整性、同次累计与复验、工作树锁与拥有者取消清理、可核对输入的准备缓存；原生框架负责收集、调度、worker池与原始逐例生命周期。

调度选择以同候选同覆盖真实资源隔离的三次代表测量为依据；Vitest threads/forks与单/双project同样保留实际原件，不把子集wall-clock或运行器选择当作全量CI收益。性能数字不替代最终固定候选的独立完整验收。缓存命中仍实际执行，历史passed不自动累计，retry仍为0，缺浏览器/零收集/严格UI skip或todo/取消/报告缺损与错身份仍失败。
