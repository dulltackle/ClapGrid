# 本行菜单改由右键和键盘打开，取消行尾常驻按钮

日期：2026-11-11

面板改版采用拆列布局（`文案 | 画面素材 | 配音`），之后行尾的 ⋯ 按钮单独占用一列。在宽面板上，这一列离文案很远，每行一个按钮也增加了视觉噪音。用户确认：表格产品中“右键行打开操作”已是普遍习惯，因此取消行尾常驻按钮。本行菜单通过以下两种方式打开：

- 在行内非控件区域单击右键，包括空白处、序号和未编辑状态的文案；
- 在行获得焦点时，按 Shift+F10 或菜单键。

不显示额外的“可右键”提示。

本决定部分取代 [ADR0014](0014-row-owned-segment-actions.md) 和 [ADR0021](0021-panel-as-review-console.md) 中“行尾常驻本行菜单”“不依赖右键也能发现操作”的条款。其余内容继续适用：行内按对象归位，各区操作就地提供，配音区的下拉菜单保留。本行菜单的操作范围仍以打开菜单时的稳定片段身份为准。

## Considered Options

- 保留行尾 ⋯ 按钮，右键只作为快捷方式：符合原有原则，但正是本次改版要消除的那一列噪音。
- 去掉按钮，同时在表头常驻“右键行打开更多操作”提示：用户认为提示多余，没有采用。

## Consequences

- 只用触控、没有右键的环境无法打开本行菜单，其中的删除、在上方或下方添加等操作只能通过页脚的勾选操作或 Codex 完成。这是有意接受的代价。
- 键盘用户依赖 Shift+F10 或菜单键打开本行菜单，浏览器测试必须覆盖这一路径。
- 本行菜单关闭后，焦点回到该行本身，因为不再有专门的入口按钮。
