# 按运行时与面板身份交付前端更新

2026-10-16，用户确认落实真正的面板快更新。当前全包指纹同时标识 MCP、服务与面板，服务启动时还会把静态资源读入内存，因此需要先完整升级一次建立新机制。本记录确认设计，执行结果由对应检查和交付记录提供。

保留完整包指纹作为来源证明，另标识运行时、面板资源与协议。只有运行时身份一致、协议明确相容且变化仅涉及面板时才能快更新；旧版或未知身份继续完整更新。不会仅凭版本号相近就允许不同服务实现混用。

服务从验证后的不可变发布资源中原子切换面板快照，保留旧资源代次及失败回滚能力，避免 HTML、JS、CSS 混用。工作空间、项目数据、服务实例、绑定和任务保持原有身份；静态资源发布根不能指向项目目录。更新收据分别记录安装目标、已加载运行时和已生效面板，不把旧进程报告成已升级。

交付核对改为按角色验证：构建与安装核对完整包，实际 MCP 和服务核对运行时，实际浏览器核对面板，并继续核对协议、工作空间及服务实例。实际观察证据要求沿用现有交付门槛。

## 已确认边界

- 本轮实现真正的面板快更新，无需重启服务或 MCP。
- 首版仅在项目空闲、相关面板没有编辑或播放时应用并刷新；忙时保留待应用更新，不中断任务、不丢草稿，恢复稳定片段身份及勾选范围后才恢复操作。
