# 检查按工作树互斥，正式验收先预检并集中复验失败项

> 2026-10-18 更新：自研工作树锁、强制预检与集中失败复验的结构要求已由 ADR0011 替代；必要产品资源清理继续验证。当前采纳设计见 [ADR0011](0011-native-test-frameworks.md)，代码迁移由 [#192](https://github.com/dulltackle/ClapGrid/issues/192) 承接。

2026-10-16，用户确认复盘中的三项修复策略：同一工作树的完整开发检查和正式验收互斥，重复启动默认拒绝；显式取消后等待本次拥有的子进程退出，不影响其他工作树。此决定收紧 ADR 0003 中开发检查与独立正式验收可并行的运行策略，保留独立检出、源码身份与完整验收的证据边界。

正式验收在独立检出中先执行适用预检；已有失败先集中复验，全部通过后才能进入完整检查。完整测试默认收集所有失败，保留原始日志和结构化清单；用户仍可主动取消。取舍是增加一次较短的预检，换取旧断言和已知失败在完整运行之前暴露。缓存编译产物、复用浏览器及扩大并发不在本次范围。
