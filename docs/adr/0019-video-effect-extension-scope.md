# 首版之后的视频效果扩展范围

日期：2026-11-07

状态：已采纳。修订[产品契约](../product-contract.md)的字幕规则；不改变首版非目标中的“语音识别”“逐字高亮字幕”“发布级特效”和 [ADR0015](0015-page-rendering.md) 的“页面音频”排除项。实现见 [#316](https://github.com/dulltackle/ClapGrid/issues/316)、[#275](https://github.com/dulltackle/ClapGrid/issues/275)、[#310](https://github.com/dulltackle/ClapGrid/issues/310)、[#311](https://github.com/dulltackle/ClapGrid/issues/311)、[#276](https://github.com/dulltackle/ClapGrid/issues/276)。

## 背景

为提升成片效果，字幕分页、声画对齐、发音回听和背景乐都触及首版非目标。2026-11-07 的一次付费探测确认，TokenDance 的 `seed-tts-2.0` 在配音流中返回字级时间戳（每个字的起止秒数与置信度）。

## 决策

- **配音时间戳来自供应商，不是语音识别。** 配音结果保存供应商返回的字级时间戳，生命周期与配音一致。已有配音缺少时间戳时不标为待更新，依赖时间戳的功能退回不依赖时间戳的做法，避免促使用户付费重新生成。
- **字幕分页属于风格。** 产品只向风格字幕模块提供文案、片段时刻、配音时长和可选的字级时间戳。风格在文案超出字幕保留区时分页：有时间戳时按每页首字换页，没有时按字数比例分配。产品不计算切分点，也不做手工时间对齐；分页参数是风格约定中的建议值，产品不校验。逐字高亮不是产品要求，风格可以自行使用时间戳做强调。
- **声画对齐只作为自检警告。** 业务 MCP 向 agent 提供字级时间戳；页面可声明关键动作锚定的口播文字，页面画面自检报告偏差，超过 0.2 秒时警告，不阻止预览，不作为审阅证据（[ADR0005](0005-review-evidence-boundary.md)）。时间戳不单独计入预览内容身份，因为配音已经计入。
- **发音回听是制作工具，产品不做语音识别。** 识别模型作为可选组件，结果只辅助发音听审，不替代人工听审，也不自动重新生成配音。供应商时间戳只反映输入文本，不能证明实际读音。
- **项目级背景乐不属于“发布级特效”。** 背景乐由用户导入，许可由用户负责，只在全片导出时混入，有人声时按固定参数压低，混音后再做响度标准化。页面不发声，提示音与风格声音调色板另行讨论（[#317](https://github.com/dulltackle/ClapGrid/issues/317)）。

## 否决的方案

- **维持整句同时显示**：多句片段的字幕铺满保留区，难以阅读，也容易遮挡画面。
- **由产品计算切分点再交给风格**：切分与排版、换行相互影响，风格已经拿到全部输入，产品再算一遍会出现两套口径。
- **把语音识别纳入产品获取时间戳或校验读音**：时间戳可以直接从供应商获得；读音校验依赖数百 MB 的模型，作为制作工具不改变产品范围和三平台交付。
- **背景乐进入片段合成预览**：背景乐按全片长度循环，单个片段的预览无法代表最终效果，还会让预览随背景乐设置失效。
