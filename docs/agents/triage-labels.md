# Triage 标签

| 标准角色 | 仓库标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待维护者评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 规格充分，可由 Agent 实现 |
| ready-for-human | ready-for-human | 需要人工实现 |
| wontfix | wontfix | 不予处理 |

技能提及某个分类角色时，使用此表对应的仓库标签。
后续调整命名时，修改“仓库标签”列。
