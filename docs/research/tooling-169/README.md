## 慢点处置

历史定位来源是 PR #160 的原生报告（run `39095676733`、artifact `12125158789`），仅用于定位，不能与本机测量相减：

- `browser-build-cache` 42 项合计约 113.237 秒。删除的两项冻结全构建比较合计约 2.233 秒，内存次数测试约 7 毫秒。
- CSS 环境专项约 13.518 秒、扫描增删两项各约 11.55 秒、资源恢复约 9.769 秒。保留这些真实编译与跨进程保障；不能以旧私有实现比较替代资源或工具失效验收。
- 同一历史原生来源还记录：Playwright 适配专项 20 项约 176.645 秒，统一证据专项 27 项约 103.079 秒，Vitest 适配专项 17 项约 16.913 秒。这些实际嵌套执行覆盖执行者接入、失败定位、旧报告/身份拒绝和完整清单；本票保留其真实故障注入。没有足够证据用更低成本入口替代时，不删除保障。
- Vitest/Playwright 的剩余适配仍负责原生报告、完整集合、执行身份及失败定位；#163 已移除 Vitest 重复官方 JSON 和 Playwright 重复结果扫描。本票不重复修改它们。
- 浏览器启动专项只有两项，分别验证空端口文件延后写入和未启动的有界失败，保留其故障定位价值。
- `test-evidence` / `test-reporting` 的真实公开入口故障注入及报告完整性校验继续运行；不以假的成功报告或退出码代替真实执行。

## 验证与测量

本票改变的是冗余实现与测试，不新增行为。采用已有真实外部保障在删减前后运行，避免为删除死代码编造实现镜像测试。独立 OCR 审查还需判断上述对应是否完整。

同机三次热点前后样本、定向回归和类型检查的原始记录位于本次 run 目录 `tooling-169/`。性能热点使用 Node 公开 `--test` 入口，固定文件、名称集合、并发、字节码和浏览器构建缓存条件；删除的内部测试不是收益的行为覆盖依据，表中保留的外部回归共同进入同一组测量。范围之外的专项仍须通过受影响回归及集成候选完整验收。

本机静默窗口中，代表组原版本三次为 10.412 / 10.286 / 10.379 秒，候选三次为 8.666 / 8.491 / 8.578 秒；中位数 10.379 → 8.578 秒，减少 1.801 秒（17.36%）。该组包含保留的七项真实外部保障；原版本额外运行三个被删内部重复项。此数字只表示这组冗余成本，不代表整个缓存文件、完整 PR 门禁或实际浏览器执行的改善。

两组使用同机 Node 22.23.3、单文件串行、关闭 Node 字节码、每项隔离新构建缓存、固定 `BROWSERSLIST_IGNORE_OLD_DATA=true` 且没有竞争检查。原始 native JSON / TAP、每次 nonce、文件 SHA256、完整命令及条件在 `tooling-169/{before,after}/`；源码恢复读回凭据为 `baseline-restored.json` / `candidate-restored.json`，汇总为 `comparison.json`。

候选受影响完整回归为缓存 39 项、浏览器启动 2 项、报告 2 项，共 43/43 passed、无 skip/todo；原生与统一报告在 `tooling-169/regression*.json`、完整 TAP 在 `regression.log`。`npm run typecheck` 通过。以上是开发检查；独立固定提交完整验收由集成候选另行执行，文档整理后不改写此前报告身份。
