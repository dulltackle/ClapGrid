## 范围和限制

供应商协议于 2026-09-28 对照 <https://tokendance.space/docs/protocol-ark-tts.md>：固定单向 SSE 端点、模型请求头、三种规定音色、语速 -50～100、原速 0、24 kHz MP3；音量与高级参数省略。

自动化测试仅替换外部供应商 HTTP 边界，使用临时真实 SQLite 与服务，不发付费请求。随后使用仓库已有本机 `.env`，通过同一服务配置入口显式指定该文件，执行一次真实合成；密钥没有输出或复制进临时视频项目。默认用户配置路径仍是 `~/.config/clapgrid/.env`。

当前产品没有切换项目或导出入口，未知 API 拒绝请求；后续实现这些业务能力必须复用任务锁。该两项当前没有可执行的完整用户流程，不能声称已完成端到端验证。批量配音、音频历史数量策略及导出属后续事项。
