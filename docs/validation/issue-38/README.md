## 验证边界

2026-10-03，沿用真实 React 主视图、生产样式和 AG Grid，仅在既有 HTTP 客户端边界提供可控响应并记录请求。自动化视口为 1600×1000、420×1000；Codex 内置浏览器设置 420×720。未更改服务契约、导出范围或配音能力。

## 行为结果

- 先运行新增浏览器回归，宽窄视口均在「无勾选时收起数量及批量操作」断言失败；加入条件显示后通过。筛选始终可用；勾选显示、取消全部收起。
- 勾选第一、第二段后筛选到第二段：数量仍为 2，明确包含筛选隐藏项，同步请求保留两个 ID。筛选表头取消只取消可见勾选，隐藏项继续计数。
- 删除请求包含第一、第二段的完整预期快照；返回后仅第三段存在，数量与批量按钮收起。
- 按序号倒序显示、筛选到第二段后，上移请求把完整项目顺序从 `[a,b,c]` 改为 `[b,a,c]`，下移恢复；筛选隐藏该单选后继续下移得到 `[a,c,b]`。首末边界、多选禁用与项目序号均验证。
- 真实文案编辑、项目修改权占用、任务锁定时批量按钮禁用。勾选同步失败和连接关闭均清空选择，底部仍有断线提示与重连入口；重连后可以重新勾选。
- 有勾选时宽窄视口均无页面横向或纵向溢出；表格保留内部滚动。
