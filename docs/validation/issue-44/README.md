# 当前对话面板勾选隔离验证

## 实现范围

表格长连接在服务完成宿主工作空间核对后，绑定签名 URL 中的对话身份。查询、按范围修改与批量配音从同一可信身份解析勾选；不接受业务参数传入对话身份。

查询仅返回当前对话的面板及勾选。没有关联、空选择、断开或旧面板身份返回不可用；同一对话多个面板且未明确面板身份返回歧义。响应提示明确指定片段，绝不自动扩大到全项目。即使提供 `tableId`，读取、改变勾选和释放连接也要属于当前对话。显式片段、条件和全项目范围继续遵循原有身份及快照校验。

关闭或重连创建新的面板身份；旧身份不能重新写入勾选。面板的筛选保持原有本地状态，筛选隐藏项仍在勾选范围内。任务与内容仍在项目内共享，不随面板断开取消或自动重试。

## 自动化证据

`tests/thread-selection.test.ts` 经打包后的 `runtime open` 建立两个对话入口，使用表格 HTTP 和 stdio MCP 验证：

- 一个对话没有面板时，不采用另一个对话的唯一面板。
- 两个对话勾选不同片段，查询、修改与配音范围各自独立。
- 外部对话的 `tableId` 不能绕过查询、修改、配音、更新勾选或释放的归属校验。
- 当前对话多面板、空选、断开、重连旧 ID 明确拒绝；显式指定片段继续可用。
- 过时文案快照不能覆盖新内容。

宿主 app-server 由测试替身提供，不能视为真实宿主双对话验收。批量配音使用空文案触发拒绝，只验证固定的目标身份，不调用真实供应商。

相关现有回归：`tests/selection-panel.test.ts` 验证筛选不改变隐藏项的勾选范围及重连操作；`tests/organization.test.ts`、`tests/speech-batch.test.ts`、`tests/mcp.test.ts` 验证稳定身份、快照和既有业务边界。
