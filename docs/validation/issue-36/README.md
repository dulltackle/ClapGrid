# #36 紧凑主视图验证

## 环境与测试边界

2026-10-03，使用真实 React 主视图、生产样式与 AG Grid，只在既有 HTTP 客户端适配边界控制响应。未改变 HTTP／MCP 契约、项目持久化格式或业务服务。Chrome 自动化视口为 1600×1000 和 420×1000；Codex 内置浏览器实测 420×720。布局数据含 60 个口播片段，覆盖正常编辑、详情、任务及异常状态；既有浮层回归另含长素材名称、保留音频、虚拟滚动与合法删除／重排。

## 已执行

- 正常编辑不显示设置、历史、配置说明；新增、导出、更多与筛选可见。五项迁移入口均打开有名称的模态层，关闭后返回更多；诊断从底部进入。浮层边界在视口内，无横向溢出，打开／关闭不改变表格外框位置或高度。
- 表格实际占满剩余空间，五个业务列可通过内部横向滚动访问，多片段使用内部纵向滚动；未增加页面滚动。原列宽调整设置保持，条件批量操作和单元格精简不在本事项范围内。
- 主视图导出与取消失败跨正常轮询、详情开关、连接失败与恢复持续显示；连接恢复只清除连接错误。关闭任务详情后查询计数继续增长，任务锁定及当前进度继续可见。
- 筛选和勾选后导出请求仍只传项目服务地址，不包含范围参数。导出锁定后阻止重复导出，取消、任务标识、成片预览链接和原片下载链接仍可访问。
- 配音失败、结果未知且可能已计费、导出失败／中断及批量进度在底部可感知；筛选隐藏片段仍有异常摘要。任务详情可查看配音、批量操作及请求标识。异常和轮询均不主动打开浮层或抢焦点。
- 勾选同步断开后底部持续提示，项目轮询不清除它，主动重新连接后才清除对应异常。
- 导出设置保存失败关闭后仍在底部显示，再次查看不清除错误；明确成功保存后清除。多行文案按非空行新增，提交中阻止重复操作与关闭，成功后清空已提交文案并释放修改权。声音设置仍即时保存，提交中保持互斥。
- 既有浮层与编辑测试经新入口回归：设置连续保存与关闭限制、字号草稿、视频导入取消和迟到响应隔离、素材编辑取消／保存、焦点恢复与筛选勾选保持。
- 初次读取、读取失败、成功空项目分别显示对应提示；读取失败恢复为空项目时，空态也更新。

## Codex 宿主实测

使用当前任务的 Codex In-app Browser（browserId 2、tabId 1），打开临时本地验证页 `http://127.0.0.1:48736/`。验证页复用客户端替身，未接触实际项目或调用计费服务。代表性任务和异常由验证页初始化响应提供；复杂时序由上述自动化覆盖。

- 正常页表格外框 top=190、height=441、bottom=631；底部状态栏 top=639、bottom=712，页面尺寸及滚动尺寸均为 420×720。表头 top=191，首行 top=232，可直接访问。
- 横向滚动容器可见宽 387px、内容宽 1280px；纵向可见高 383px、内容高 2400px。实际滚动后 top=2017、left=893，末列「画面说明」与末行可访问，页面没有滚动。[滚动末端截图](codex-420-scroll-end.png)。一次 Control+End 未移动表格，随后通过滚动与拖动滚动条完成验证，没有将无效按键计为成功。
- 打开声音设置后表格仍为 top=190、height=441；浮层左右边界 17–403px，无横向溢出。关闭后焦点回到「更多」。
- 导出任务进行中，项目锁定及 18/60 进度持续显示；任务详情可查看任务 ID 和取消入口，关闭后仍显示进度。
- 导出失败、配音结果未知和提交拒绝同时可见；任务详情关闭后错误保留，焦点回到「任务详情」。异常页表格仍保留 387px 高度。
- 默认 1280×720 宿主中拖动「序号」列调整手柄，宽度从 80px 变为 130px，确认列宽调整生效。
- 宿主视口验证完成后恢复默认尺寸。截图包含内置浏览器内容，不包含宿主窗口边框。
