# #25 全片粗剪导出验证

日期：2026-09-28。环境：当前 Linux 工作区，Node.js、FFmpeg/ffprobe、Fontconfig 与支持 Unicode 自动换行的 libass。

## 已执行的验证

- `tests/export-tasks.test.ts` 经项目业务公开接口验证：先受理、任务标识、重复提交、任务锁、空项目与设置问题汇总、逐片段视频/配音缺失、修改占用、未结束配音。
- 使用真实合成 MP4 和模拟供应商返回的真实 MP3，不发送付费配音请求。真实渲染输出以 ffprobe、解码像素和频率相关性验证：1920×1080、指定编码帧率、项目顺序、指定视频起点、冻结末帧、等比留边、配音替换原声、烧录字幕。
- 导出开始后修改外部原视频及配音文件，正在运行的任务仍使用已复制的素材快照；最近一次配音生成失败不影响有效旧配音导出。
- 再次导出使用新文案、字号、编码及帧率，输出不同文件，原成片字节不变；连续中文案自动多行显示，无长文案警告或片段拆分。
- 取消真实渲染立即显示清理状态，清理完成前不能取得修改权；终态后仅保留已有成片，延迟检查无半成品重新出现。
- 模拟外部编码器在渲染阶段生成半成品后失败，结果定位到片段，删除本次临时文件并恢复修改权。
- 原视频变短、视频损坏、配音待更新及音频损坏均反馈相应片段，不跳过片段或自动配音。
- `tests/export-service.test.ts` 经实际 HTTP 与 MCP SDK 协议验证同一任务、取消、进度、状态锁，以及拒绝 selected 范围参数。
- `tests/export-settings.test.ts`、`tests/video.test.ts` 回归通过，包括全部支持编码/帧率、字体失效、组件不可用、媒体时长与原始视频导入。

- 审查后补充末帧持续区间（1 秒素材从 0.99 秒开始）、非方形像素 SAR=2、非整帧音频时长 0.83 秒场景。成片 AAC 包持续时间与 PTS 逐包检查，确保不因中间视频帧取整插入播放时间戳间隔。
- 浏览器兼容预览使用 VP8/Vorbis WebM；真实探测两条轨道，原始 MP4 独立保留。

## 产品操作验证

使用独立临时演示项目，在 Codex 内置浏览器中打开构建后的表格，采用合成媒体与预先生成的测试配音，不访问用户项目或在线配音服务。

- 筛选为“欢迎”并仅勾选第一个片段后点击导出，全片任务仍为 2 个片段，最终成功 2/2。
- 运行时新增、导入、声音和逐行重新生成控件禁用，试听仍可用；成功后恢复编辑。
- 展开成功任务可看到绝对路径、冻结提示和打开入口。
- 实测内置浏览器不支持直接解码当前 MP4，因此提供独立兼容预览及 MP4 原片下载。点击打开后，浏览器播放到 6.019 秒结尾，`readyState=4`、`error=null`，显示烧录的多行字幕；原片仍为 1920×1080 MP4。
