# #35 详情浮层验证

## 环境与边界

2026-10-03，在 Linux 的真实 Chrome 中渲染 React 主视图、AG Grid 及生产样式。测试仅替换现有 HTTP 客户端模块，通过可控响应验证保存、取消、修改权及合法项目更新。键盘通过 Chrome DevTools Protocol 发送真实按键，覆盖原生 Tab、Shift+Tab、Enter 和 Esc。

视口为 1600×1000 和 420×1000；50 个口播片段，包含长素材名称和保留音频。测试中的媒体 URL 不提供实际媒体文件，截图中缩略图缺失及媒体错误是测试数据的限制；本工单不以这些截图证明媒体播放质量。

## 已执行的行为

- 全片导出设置、素材调整、视频预览、配音试听、保留音频的可访问名称、焦点进入及明确关闭入口。
- 浮层内双向 Tab 循环，包括原生媒体控件；背景由原生模态层隔离。
- 表格按钮通过键盘打开详情，关闭回原单元格；轮询重建按钮后仍可返回。
- 正常关闭保留表格横纵滚动、筛选和勾选；原片段删除回到邻近可见行，空表回到筛选入口；合法重排到视口外缓冲行时，滚动至可见位置再恢复焦点。
- 连续查看设置、历史、预览和试听没有保存、修改权申请、配音／导出提交或重试效果。
- 导出设置保存期间 Esc 不关闭；全部控件禁用时仍保留焦点；字号未提交时 Esc 保留草稿，完成保存后关闭并释放修改权。
- 异步申请素材修改权期间打开音频详情，上层关闭后回到仍打开的详情，最后回到各自原列，不遗留修改权。
- Codex 修改期间设置保持只读；素材取消不保存草稿；素材保存生效；导入处理中 Esc 沿用原有取消流程，迟到结果不会释放新编辑的修改权。
- 浮层边界位于视口内，内容无横向溢出。
