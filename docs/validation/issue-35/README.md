# #35 详情浮层验证

## 环境与边界

2026-10-03，在 Linux 的真实 Chrome 中渲染 React 主视图、AG Grid 及生产样式。测试仅替换现有 HTTP 客户端模块，通过可控响应验证保存、取消、修改权及合法项目更新。键盘通过 Chrome DevTools Protocol 发送真实按键，覆盖原生 Tab、Shift+Tab、Enter 和 Esc。

视口为 1600×1000 和 420×1000；50 个口播片段，包含长素材名称和保留音频。测试中的媒体 URL 不提供实际媒体文件，截图中缩略图缺失及媒体错误是测试数据的限制；本工单不以这些截图证明媒体播放质量。

## 已执行的行为

- 全片导出设置、素材调整、视频预览、配音试听、保留音频的可访问名称、焦点进入及明确关闭入口。
- 浮层内双向 Tab 循环，包括原生媒体控件；背景由原生模态层隔离。
- 表格按钮通过键盘打开详情，关闭回原单元格；轮询重建按钮后仍可返回。
- 正常关闭保留表格横纵滚动、筛选和勾选；原片段删除回到邻近可见行，空表回到筛选入口；合法重排到视口外缓冲行时，滚动至可见位置再恢复焦点。
- 连续查看设置、历史、预览和试听没有保存、修改权申请、配音／导出提交或重试效果。
- 导出设置保存期间 Esc 不关闭；全部控件禁用时仍保留焦点；字号未提交时 Esc 保留草稿，完成保存后关闭并释放修改权。
- 异步申请素材修改权期间打开音频详情，上层关闭后回到仍打开的详情，最后回到各自原列，不遗留修改权。
- Codex 修改期间设置保持只读；素材取消不保存草稿；素材保存生效；导入处理中 Esc 沿用原有取消流程，迟到结果不会释放新编辑的修改权。
- 浮层边界位于视口内，内容无横向溢出。

## Codex 宿主补验

2026-10-03，在用户要求验证未勾选项后重新连接成功。使用当前会话的 **Codex In-app Browser**（browserId `2`、tabId `1`）打开当前提交 `333629a` 的真实 React/AG Grid 主视图。通过内置浏览器的 viewport 能力设置 **420×720** 窄视口，结束后恢复默认 **1280×720**。这是在 Codex 内置浏览器内的尺寸验证，不是上一轮外部 Chrome 的窄视口替代；截图只包含浏览器内容，不包含整个宿主窗口边框。

页面地址 `http://127.0.0.1:48735/`，使用已有 `tests/helpers/editing-fixture.ts` 的 HTTP 客户端替身和 50 个片段；保留真实轮询、编辑仲裁、AG Grid 及生产样式。新增的测试视频、缩略图与静音音频均为本地生成数据，不访问实际项目、不调用付费服务。本轮仅补验证证据，没有修改产品代码。

已实测：

- 设置、素材调整、视频预览、保留音频、配音试听均进入有名称的模态层；所有浮层左右边界在 17–388px 之间，内部宽度与滚动宽度一致，无横向溢出。
- 设置浮层连续 4 次 Tab、4 次 Shift+Tab 均保持内部焦点；素材和音频浮层也经过双向键盘循环。
- Esc 关闭设置回到“导出设置”入口；关闭素材与预览回到片段 `segment-0` 的画面素材列；关闭保留音频回到该片段的配音列。
- 将素材起点草稿改为 8 后取消，表格仍显示原起点 2 秒。全过程筛选“保留片段 1”和原片段勾选保持不变。
- 字号草稿改为 48 后按 Esc，浮层保持打开并提示“字号尚未保存，请先离开输入框完成保存”；Tab 完成保存后 Esc 可以关闭，焦点返回设置入口。
- 视频预览显示本地生成的测试画面，试听显示原生音频控件。此项用于确认媒体控件在宿主中的布局与焦点，不作为真实配音质量验收。
