## 实际交互结果

- 修改前实际面板为六列，尚不满足五列表头要求；修改后宽屏恰好显示“序号｜文案｜画面素材｜配音｜画面说明”，旧表头消失。末列无必填标识。
- 1440 × 900 视口：页面滚动宽度 1440px，五列宽度分别为 80 / 840 / 150 / 140 / 180px，文案保留主要阅读空间。拖动首列右边界 30px 后，序号变为 110px、文案变为 810px，其余列不变；刷新恢复初始宽度。
- 327 × 760 视口：页面滚动宽度 327px，无页面整体横向溢出。表格内部可视宽度 293px、内容宽度 750px；文案最小宽度仍为 200px。
- 从页面按两次 Tab，先经过诊断入口，再进入“序号”表头；按四次右方向键，焦点依次到达“文案”“画面素材”“配音”“画面说明”。末列自动滚动到可见区域，内部 scrollLeft 为 457px，末列表头横坐标 130px、宽 180px，焦点轮廓清晰可见。列虚拟化会按滚动位置改变 DOM 中的表头集合，不代表业务列被隐藏。

- 延迟请求时页面和表格均显示“正在连接本地服务…”；HTTP 500 时显示“服务连接失败，请通过 Codex 检查本地服务。”和“暂时无法读取口播片段”，不会误显示正常空态。
- 实际页面保持白色背景、灰色表头及原有字体、边框；没有新增素材管理、配音或说明编辑控件。
