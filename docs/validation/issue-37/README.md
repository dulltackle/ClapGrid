- 超过 800 字且含换行的文案在浏览时显示三行摘要；完整文本仍保留，短文案正常显示。先运行回归得到单行高度失败，再实现并通过。

- 再次进入编辑可访问完整保存结果，连续保存成功。断线取消未提交草稿且不增加请求；已保存内容保留，状态栏显示取消提示。保存失败释放修改权并保留错误提示。
- 原有编辑时序、布局及浮层回归继续执行。全文编辑期间的仲裁沿用原实现；没有新增后端测试层。
