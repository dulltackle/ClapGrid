## 发现与修复

原实现将「配音任务尚未结束」放入导出任务的校验问题中，仍会受理导出、创建任务及临时工作目录。现在在创建任务之前检查配音锁，表格 HTTP 与业务 MCP 共用该拒绝行为，反馈「配音任务尚未结束，不能开始导出；允许查询和试听」。其他可执行导出的素材及设置问题继续由导出前置校验汇总。

## 项目切换缺口

`src/runtime.ts` 只提供 start/status/stop。已有服务的项目与指定目录不同时，无论是否存在任务，均返回「端口上的服务属于其他项目，请保留该服务并明确选择其他端口」。表格与业务 MCP 也未提供切换项目入口。这个身份校验没有依据配音状态作出拒绝，不能证明任务锁阻止切换，更不能证明任务结束后切换恢复可用。

#26 已关闭并不等于 #33 的项目切换开始条件满足。按本事项「只补齐锁验收，不重复实现完整导出或生命周期功能」的范围，本轮不自行设计项目切换功能。
