# 有界等待与项目资源清理（#203）

测试等待与资源清理遵循 ADR0011。正常耗时是观察结果，不设提速门槛。

## 范围

全套 Vitest 文件不使用无限 `testTimeout` / `hookTimeout`。条件等待直接使用 `expect.poll` / `vi.waitFor`；保留的导出阶段 helper 只处理具体配音／导出任务，遇到失败、取消或中断终态后在轮询外报告实际任务。提交、启动和写入动作在观察回调之外执行一次。

媒体、构建、归档及后台 CLI 测试使用异步命令；正式追踪脚本和 GitHub 辅助查询同样采用可取消异步调用。具体命令夹具接入 `TestContext.signal`，在 Node `spawn` 返回时同步记录出生身份，补充观察真实亲子边；这使 detached 服务在 CLI 尚未回执时已经有清理责任。清理仅作用于这些已确认拥有的进程，拒绝 SIGTERM 时有限升级为 SIGKILL，并确认原身份退出。身份不明或退出未确认时失败并保留目录与拥有权证据。

项目 fixture 只负责本例的业务、HTTP 服务、MCP／长连接、命令和目录，使用一个原生 `onTestFinished`。连接先在 2 秒内并行关闭，再在总计 6 秒内关闭业务及服务，最后保留至总计 8 秒用于进程兜底；同阶段的独立资源均获得尝试机会，共享一次绝对截止时间；只有全部关闭及退出得到确认后才删除目录。原生报告同时保存测试失败和清理失败。服务 Promise 在创建时登记，超时后迟到返回的服务仍会关闭；初始化不能确认时保留现场。

未引入产品事件或可注入时钟、通用等待器、执行器、watch、报告格式或结果认证。受控竞态、心跳、连接存活和停止后的迟到写入观察仍保留完整时间窗口。

## 时间预算

| 边界 | 预算 | 用途与依据 |
| --- | --- | --- |
| Vitest 默认测试 | 15 秒 | 类型、HTTP／SQLite、短 CLI 和普通媒体场景；按全套实际运行核对 |
| 默认钩子 | 10 秒 | 原生边界；项目资源统一钩子另有 9 秒框架时限 |
| 原生条件轮询 | 5 秒、20 ms 间隔 | 只观察状态；具体恢复或导出保留 10／60 秒有限例外 |
| 每例项目清理 | 总计 8 秒 | 所有具体项目资源共享截止时间，多个钩子不各领一份预算 |
| 普通外部命令 | 10 秒（GitHub 查询 120 秒、正式 strace 专项 180 秒） | 短构建／媒体／CLI；服务常驻观测命令显式 60 秒 |
| 命令终止 | SIGTERM 后 200 ms，再最多 1500 ms 确认 | 只针对本例登记的出生身份；命令退出保护另有 2500 ms 有限余量 |
| 显式测试例外 | 20／30／40／60／120 秒 | 独立异常运行、迁入／在途编辑、归档发布、插件与共享服务、真实导出崩溃恢复；沿用各场景具体有限预算 |
| 独立异常运行 | 内层 0.5／2.5 秒，外层 14 秒 | 外层必须观察实际退出；若需要外层兜底终止，测试失败，不计为自行收尾成功 |

短 Git 元数据与可信版本探测保留 5 秒及 SIGKILL；少数纯同步的真实编码器替身调用保留 `timeout: 10000, killSignal: 'SIGKILL'`，只运行已知直接编码器并继承输出；外层仍记录该进程的出生身份与后代。这不是以仅发送 SIGTERM 的同步 timeout 证明返回上界。

## 验证入口

- 定向开发检查：类型检查及受影响 Vitest 文件按实现迭代执行。
- 独立异常专项：`npx vitest run tests/bounded-run.test.ts tests/command-exit.test.ts`。覆盖任务不完成、测试超时、原生用户取消、拒绝正常终止、清理失败／耗尽预算、命令超时同时退出未确认、未就绪回执、部分初始化失败及身份未知。原生 metadata 记录每个独立运行的耗时、退出状态和目录保留结果。

用户取消专项通过 Vitest 原生 `cancelCurrentRun('keyboard-input')` 触发测试上下文取消。非交互 CLI 的直接 SIGINT 是框架立即退出路径，未把它作为协作清理成功的证据。SIGKILL、宿主强制终止或断电也不提供清理已完成的保证。
